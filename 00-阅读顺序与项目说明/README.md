# 星衍树版权二创平台一期 MVP 前端 AI 开发包

本目录供完全不了解项目的前端 AI 使用。文件为 `功能结构图\v0.4` 的副本；开发应在实际 Vue 前端代码仓库完成，**不要修改本开发包中的需求基线**。

## 1. 项目背景

星衍树是城市文化 IP 的版权共创与运营平台。平台将 IP 权利资料、授权、创作者二创、文创商品、文旅活动、消费者交易/预约、履约、售后、分账和真实存证串为可追溯闭环。

一期核心业务：城市运营录入 IP → 版权/合规确权并确认固定方案 → 平台管理员上架 → 创作者实名购买授权 → 作品确权 → 商品/活动自动校验发布 → 消费者 H5 下单或预约 → 发货/核销 → 售后、分账、结算与存证。

## 2. 前端端与角色

### 2.1 统一管理后台（Vue）

平台管理员、集团管理层、城市运营、版权/合规、创作者、财务、履约客服共用后台，通过后端 RBAC 与数据范围控制可见菜单和数据。

- 城市运营：只录入本城市 IP、补充材料、选择初步方案；不创作或审核商品/活动。
- 版权/合规：审核 IP 权利、确认方案、审核/确权作品。
- 平台管理员：账号权限、平台配置、固定模板、IP 上架和风险处置。
- 创作者：实名、IP 授权购买、作品、商品、活动、本人履约/结算。
- 财务/履约客服：分别处理退款/结算与发货/核销/售后。
- 集团管理层：只读经营与风险看板。

### 2.2 消费者 H5（Vue）

消费者 H5 的唯一交付入口是 `06-消费者H5开发包`。游客只可浏览商品、活动和平台服务信息，**不展示任何 IP、创作者、品牌、授权或分账信息**。消费者使用短信验证码注册/登录；订单、地址簿、支付、履约和售后须以该目录内“当前可联调边界”为准。

## 4. 前端开发强制约束

- 复用实际项目的 Vue、路由、请求封装、组件库、图标和样式约定；不要无关重构或新增大型框架。
- 下拉、单选、复选、状态文字来自字典/API；不在前端写死业务状态或自行推导可操作动作。
- 使用接口返回的 `availableActions`、权限与状态控制按钮。写操作按接口规范带 `Idempotency-Key` 和版本号（适用时）。
- 金额按字符串处理，业务 ID 不转换为 JavaScript `Number`。
- 所有页面具备加载、空态、无权限、字段校验、接口失败、处理中和状态冲突反馈。
- 文件只传递/保存 `fileId`；下载只使用后端签发的短期 URL，不展示存储键、合同私有地址或敏感信息。
- 商品先经系统自动校验，再由版权/合规人员完成版权初审与合规复核；活动为系统自动校验、自动发布，不得制作活动人工发布审核页面或按钮。
- 收费订单调用 `POST /payments/wechat-h5/initiate` 后跳转返回的 `h5Url`；从微信返回页面后主动刷新订单，仅以后端确认的支付状态为准。
- 消费者 H5 只展示通俗版权说明，禁止展示授权边界、合同、权利证明、实名、内部分账、审核意见和存证技术回执。

## 5. 一期明确不做

数字人民币、自动续期、授权成功后的取消退款、发票、活动改期、提货自取、商品草稿、多账号、优惠券/会员/复杂营销、投诉工单，以及活动人工发布审核。

## 6. 每次领取前端任务

1. 确认页面编号、角色、路由和关联 API；
2. 阅读页面字段清单、状态机、OpenAPI 和关联测试用例；
3. 复制 `04-开发执行与测试/AI单任务开发模板.md` 的“前端页面开发模板”；
4. 仅实现该页面/组件与直接依赖，完成交互和自测；
5. 输出变更文件、页面/接口绑定、测试结果和需要后端/产品确认的事项。
