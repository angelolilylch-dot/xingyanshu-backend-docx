# 星衍树版权二创平台一期MVP需求基线与范围说明

版本：v0.4

状态：已确认基线，作为一期开发、数据库设计、API设计、AI任务拆分和验收的最高依据。

## 1. 文档目的与优先级

本文件用于统一产品、设计、前端、后端、测试和 AI 辅助开发的理解，明确一期 MVP 的业务边界、角色职责、核心流程、数据规则和验收标准。

如本文件与原型、任务计划、接口草案或后续临时说明不一致，以本文件的最新确认内容为准。新增需求不得直接改变一期范围，应进入变更记录并评估是否排入后续版本。

## 2. 一期产品范围

### 2.1 建设两个前端项目

#### A. 统一管理后台

面向平台内部和创作者使用，采用角色权限控制菜单、页面、按钮和数据范围。创作者也在管理后台的创作者工作台中完成授权购买后的创作操作。

覆盖角色：平台管理员、集团管理层、城市运营人员、版权/合规人员、创作者/二创作者、财务人员、履约客服人员。

#### B. 消费者 H5

面向消费者和游客，提供公开浏览、商品购买、文旅活动预约、微信支付、物流查询、活动核销码、退货退款和个人中心。

消费者 H5 不提供 IP 授权购买、作品提交、商品创建或活动创建功能。

### 2.2 一期核心目标

完成以下闭环：

```text
城市运营录入IP
→ 选择平台固定授权方案和分账方案
→ 版权/合规完成IP与方案确认
→ IP进入创作者IP商城
→ 创作者注册、实名、购买授权
→ 生成虚拟合同和授权凭证
→ 创作者提交二创作品并完成版权/合规审核
→ 创作者创建商品或文旅活动
→ 系统自动校验授权边界和第三方敏感内容
→ 校验通过后自动发布到消费者H5
→ 消费者购买商品或预约活动
→ 微信支付
→ 商品物流配送或活动现场核销
→ 退货退款/售后
→ 订单完成
→ 系统自动计算分账
→ 财务复核并线下结算
→ 关键业务材料真实存证上链
```

## 3. 一期明确不做

- 不建设独立的城市运营端、独立创作者端、独立财务端或独立客服端。
- 测试环境允许模拟支付；生产环境接入真实支付 API。数字人民币暂不作为一期支付渠道，但保留统一支付适配接口。
- 不实现 N 创再次授权、多层收益树和上级创作者分账。
- 不接入智能合约自动分账。
- 不支持授权自动续期，也不支持人工续期；到期后只能重新购买新的授权方案。
- 不支持企业/工作室多账号和成员管理。
- 不支持创作者自行修改实名或主体信息。
- 不做商品或文旅活动草稿保存。
- 不做换货、补发、维修、在线客服和投诉工单。
- 不做发票功能。
- 不做图片 OCR、视频识别和音频识别；一般内容仍只检测提交文字。CNT-02 商品提交额外对封面、详情、SKU 配图及图片类附件调用第三方图片内容审核。
- 不做复杂 BI、可配置推荐权重和复杂组织架构编辑。
- 不做商品按重量、件数或地区自动计算运费。

## 4. 角色与职责边界

### 4.1 平台管理员

- 管理后台账号、角色、登录状态和基础权限。
- 维护平台固定授权方案、固定分账方案和固定取消/退款模板。
- 管理敏感内容检测接口配置和检测规则记录。
- 维护客服电话、服务时间和服务说明。
- 维护平台退货地址。
- 管理系统配置、日志、文件权限和数据导出权限。
- 不参与商品和文旅活动内容审核。
- 不直接修改创作者提交的 IP 衍生内容。

### 4.2 集团管理层

- 查看全集团经营、IP、授权、交易、履约、财务和风险数据。
- 查看基础报表和审批结果。
- 不参与 IP 专业审核、商品/活动内容审核和日常创作。

### 4.3 城市运营人员

- 只能录入本城市 IP 基本信息、权利人和版权材料。
- 选择平台固定的初始授权方案和分账方案。
- 补充或修改尚未完成版权/合规确认的 IP 资料。
- 不创建商品。
- 不创建文旅活动。
- 不审核商品或文旅活动。
- 不干预创作者商品、活动的发布和售后审核。

### 4.4 版权/合规人员

- 审核 IP 权利人、权属证明、版权材料和授权边界。
- 审核 IP 与平台固定授权方案、分账方案是否匹配。
- 可以确认、修改或退回授权方案绑定结果。
- 审核创作者提交的二创作品，包括文字、图片、视频、源文件和版权声明。
- 处理第三方敏感内容接口返回的疑似风险作品文本复核。
- 上传评估报告，记录报告编号、机构、日期和有效期。
- 不创建商品和文旅活动。
- 不负责商品和活动发布审核。

### 4.5 创作者/二创作者

- 自主注册创作者账号并设置密码。
- 个人或企业/工作室完成实名验证后购买 IP 授权。
- 浏览和购买 IP 商城中的授权商品。
- 查看已购买授权、合同、素材包、作品和结算信息。
- 提交二创作品。
- 基于已审核作品创建商品。
- 基于有效 IP 授权直接创建文旅活动，不强制先有二创作品。
- 创建商品和活动时不能超出授权边界。
- 商品和活动发布后通过系统自动检测，检测通过后自动发布。
- 自行发货或选择平台统一发货。
- 查看本人内容、订单、售后和分账数据。

### 4.6 财务人员

- 查看资金流水、退款流水、订单金额和分账明细。
- 复核退款金额和分账冲销。
- 复核系统自动计算的分账结果。
- 确认结算批次。
- 线下完成实际付款并上传付款凭证。
- 处理结算异议和付款状态。
- 一期不自动打款。

### 4.7 履约客服人员

- 全平台查看商品和文旅活动的履约相关内容。
- 处理商品发货、物流异常、活动核销和售后申请。
- 审核退货退款申请。
- 确认退回商品和退款条件。
- 维护商品履约过程，不审核商品或活动的发布内容。
- 只能查看授权信息摘要，不查看身份证明、版权证明原件、评估报告、授权委托书和内部合规意见。

### 4.8 消费者/游客

- 在消费者 H5 浏览公开商品和文旅活动；不提供公开 IP 介绍。
- 注册、登录、加入购物车、购买商品、预约活动。
- 查看订单、物流、核销码和售后进度。
- 不进入管理后台，不进入 IP 授权商城。

## 5. 账号、注册与实名认证

### 5.1 创作者账号

- 创作者自主注册，注册时填写账号、手机号和密码。
- 注册成功后完成主体实名认证。
- 个人创作者和企业/工作室主体均调用第三方实名接口自动核验。
- 实名状态只有：未认证、认证中、已认证。
- 未认证或认证中的创作者可以浏览 IP 商城，但不能购买授权。
- 已认证后才可以购买授权、下载素材、生成合同和创建内容。
- 同一身份证只能绑定一个个人创作者账号。
- 同一统一社会信用代码只能绑定一个企业/工作室创作者账号。
- 企业/工作室完成第三方主体认证后，可下载平台提供的《授权委托书》模板并上传盖章文件作资料留存。
- 授权委托书不作为购买前置，不需要平台管理员确认；主体真实性和购买资格均以第三方实名认证结果为准。
- 一期不支持修改个人实名信息或企业主体信息。
- 一期不支持企业/工作室多账号。
- 创作者是管理后台角色，使用手机号账号、密码和图形验证码登录；所有后台角色共用统一认证入口。消费者仅使用 H5 登录。

### 5.2 消费者账号

- 手机号为唯一账号标识，一个手机号只能注册一个消费者账号。
- 注册和登录均使用短信验证码。
- 短信验证码只用于注册和登录，不发送其他业务通知。
- 短信验证码需要有效期、频率限制、错误次数限制和发送记录。
- 一期不设置消费者登录密码。
- 首次及后续短信登录必须勾选用户协议和隐私政策；服务端留存同意时间与协议版本。
- 同一手机号允许多设备会话并存；退出登录只撤销当前设备会话。
- 消费者只能查看自己的订单、预约、售后和积分数据。

## 6. IP 入库、确权与商城上架

### 6.1 IP 录入主体

只有城市运营人员可以录入 IP。一个 IP 只允许登记一个原始 IP 权利人。

权利人类型支持：个人、企业、机构、集体组织。

一个 IP 只能绑定一个主归属城市。确权后主归属城市不能直接修改。

### 6.2 IP录入内容

城市运营录入：

- IP名称、IP类型、资源来源、文化背景和故事；
- IP封面图/缩略图、详情图；
- **完整入库素材包**：素材项、文件角色、可交付范围、文件 Hash 和素材包清单 Hash；该素材包是 IP 权属证据与后续创作者交付物的一部分；
- 一句话简介、完整介绍、IP特色；
- 可创作方向、适用商品类型、适用文旅活动类型；
- 地域、文化、品类和商业化标签；
- 原始 IP 权利人及权利人类型；
- 权利取得方式、权属说明；
- 版权证明类型、编号、文件和有效期；
- DCI 版权证书编号和证书文件；DCI 证书为必填项；
- 评估报告信息和文件，如有；城市运营可在录入 IP 时上传，版权/合规可后续新增或补传，均不作为 IP 录入必填项；
- 面向创作者展示的版权说明文字；
- 购买须知。

### 6.2.1 DCI 版权证书缺失与代办申请

DCI 版权证书是 IP 提交版权/合规审核和最终上架的必备材料。城市运营在尚未取得证书时，仍可完整录入并保存其他 IP 资料为草稿；不得提交审核、确权或上架。

城市运营在新增 IP 表单勾选“申请 DCI 代办”后，展开并填写联系人、联系电话、方便联系时间和补充说明，其中联系人和联系电话必填；随后只点击原有“保存 IP”动作。系统在同一事务创建 IP 和代办联系请求，并将 DCI 状态标记为“已申请代办”。DCI 代办与 DCI 证书编号、证书文件互斥，勾选代办时不得填写或上传证书。创建请求时必须固化 DCI 提交包和完整入库素材包的清单 Hash；该提交包随代办请求锁定，不能原地修改。需要补正时必须退回或终止当前请求、重新生成清单 Hash 并新建代办请求。版权/合规可按需下载系统生成的私有 ZIP 资料包，包内含代办申请 Markdown、IP 作品说明、权属证明和作品附件，评估报告可选附带。

城市运营取得证书后上传 DCI 证书文件并填写编号，DCI 状态变为“已上传”。版权/合规在 IP 审核中核验通过后，状态变为“已核验”；只有 `已核验` 的 DCI 证书才满足确权和商城上架前置条件。代办联系信息属于个人信息，须加密存储、脱敏展示并记录处理轨迹。

### 6.3 商城展示内容

IP 商城采用统一商城结构，不拆分普通授权页和买断授权页。

列表卡片展示：

- IP缩略图；
- IP商品名称；
- 简介；
- 地区；
- 授权价格；
- 授权方式；
- 可创建内容类型；
- 购买入口。

详情页展示：

- 详情图、完整介绍、文化背景和 IP 特色；
- 可创作方向和适用内容类型；
- 授权期限、授权地区和使用场景；
- 商业化、二创和 N 创说明；
- 授权名额和购买规则；
- 授权价格；
- 普通授权下创作者与平台的分账比例；
- 独家买断价格和独家范围；
- 购买须知和通俗版权说明文字。

不展示：

- 版权证明原件；
- 评估报告；
- 权利人身份证明；
- 授权委托书；
- 原始 IP 权益方、城市运营和平台的内部分账拆分；
- 内部审核意见。

商城筛选条件：IP名称/关键词、地区、IP类型、文化或品类标签、授权方式、可创建内容类型、授权期限、价格区间、上架状态。

默认推荐根据销量、购买人数、剩余名额和新上架时间自动变化，规则一期固化，不开放后台权重配置。售罄、下架、暂停或失效的 IP 不参与正常商城展示。

### 6.4 IP审核和上架前置条件

流程：

```text
城市运营录入IP（DCI 证书缺失时可保存并提交代办申请）
→ 选择平台固定授权方案和分账方案
→ 完整上传入库素材包并固定素材包清单 Hash
→ 上传 DCI 证书并经版权/合规核验
→ 版权/合规审核权利证明和授权边界
→ 版权/合规确认或退回补充
→ IP确权
→ IP 关键材料与素材包清单生成 Hash 并真实存证
→ 素材包冻结，系统自动进入 `LISTED` 上架状态并开放商城展示
```

确权并自动上架前必须满足：资料完整、唯一权利人明确、材料有效、完整入库素材包及清单 Hash 已固定、DCI 证书已上传并经版权/合规核验、主归属城市确定、授权方式确定、平台固定方案已启用且确认、价格/期限/地区/场景/内容类型/名额已配置、分账或买断费用分配规则已确认、商城展示内容完整、IP 关键材料和素材包清单均完成真实存证。确权成功且全部条件满足后，系统直接将 IP 置为 `LISTED`、素材包置为 `FROZEN` 并设置商城可见；不再由平台管理员单独点击上架。已冻结的原 IP 和入库素材包不得修改、删除、替换、追加或版本覆盖；需要新增或修正素材必须新建 IP 入库/确权记录。

## 7. 授权方案与 IP 授权

### 7.1 授权方案模型

- 授权方案由平台固定配置和维护。
- 一个授权方案可以复用到多个 IP。
- 一个 IP 一期只能绑定一个当前生效的授权方案。
- 城市运营只能选择平台方案，不能创建或自由修改方案。
- 平台管理员维护方案模板；版权/合规人员审核方案内容。
- 新方案需经过“草稿 → 待版权/合规审核 → 已确认 → 已启用”。
- 已绑定 IP 的方案不能停用、修改或删除。
- 未绑定 IP 的方案可以停用；停用后不能被新 IP 选择。
- 方案规则变化必须新建方案或新版本，不改动历史授权。

### 7.2 方案内容

方案配置：授权方式、期限、地区、使用场景、商业化权限、二创权限、N创权限、适用内容类型、授权名额、价格和分账/买断费用分配规则。

适用内容类型支持：仅商品、仅文旅活动、商品和文旅活动均可创建。

一期不限制每个创作者创建的商品数量、SKU数量、活动数量、场次数量、商品累计产量或活动累计预约人数；活动每个场次仍有独立预约上限。

### 7.3 普通分账授权

- 创作者支付授权费用后获得授权。
- 同一个创作者对同一个 IP 只能购买一次。
- 有限名额按先来后到处理。
- 支付成功后立即生效并占用名额。
- 生成授权编号、授权凭证、虚拟合同、授权边界快照。
- 创作者与平台的分账比例对创作者展示；原始 IP 权益方和城市运营的内部拆分不展示。
- 后续商品和活动订单按完整分账方案自动计算原始 IP 权益方、创作者、城市运营和平台服务费。

### 7.4 独家买断授权

独家买断针对的是原始 IP 的独家使用授权，不是版权所有权转让。

- 独家买断在 IP 上架前确定，不能由普通授权中途切换。
- 一个 IP 只能采用普通分账授权或独家买断中的一种。
- 买断费用单独设置分配规则，参与方为原始 IP 权益方、城市运营和平台；创作者是付款方，不参与该笔费用分配。
- 买断成功后，IP 从商城隐藏，停止其他创作者查看和购买。
- 买断创作者获得约定期限、地区、场景和内容类型内的独家使用权。
- 买断不转让原始 IP 版权所有权，创作者不能再次授权或转让。
- 买断后创作者创建的商品和活动，其后续收益全部归创作者。
- 原始 IP 权益方、城市运营和平台不参与后续二传收益分账。
- 平台不收取任何后续平台服务费。
- 买断商品和活动仍需通过系统授权边界校验和敏感内容检测。

### 7.5 授权确认、合同和素材

购买前确认页展示主体信息、IP、方案、价格、期限、地区、场景、内容类型、名额、合同主要条款和购买须知。创作者必须勾选同意虚拟合同后才能提交购买。

微信支付成功回调或主动查单确认成功视为合同生效。合同生成后不可修改，支持在线查看和下载，包含合同编号、双方主体、IP、授权范围、期限、地区、场景、内容类型和分账说明。合同文件生成 Hash 并真实存证。

素材包只允许已生效授权的创作者下载，且该素材包必须已冻结并取得成功存证回执；下载记录包含授权编号、合同编号、素材包清单 Hash、文件版本、下载人、时间和 IP 地址。授权到期或解除后停止新下载。

### 7.6 授权失效和解除

- 授权到期后不能续期，只能重新购买新的授权方案。
- IP/授权方案到期后从 IP 商城隐藏，停止新购买。
- 已购买创作者仍可查看历史授权、合同、凭证、订单、结算和存证记录。
- 到期或解除后不能下载新素材、创建新商品或活动。
- 商品和活动停止新的销售或预约。
- 已完成订单、合同、分账和存证记录保留。
- 因虚假资料、越权使用、侵权或重大合规风险，可以强制解除授权。
- 强制解除后，未产生订单的内容停止发布；未完成订单和未核销活动由平台管理员决定继续履约或退款；未结算金额冻结，由财务处理。

## 8. 二创作品流程

### 8.1 作品创建前提

创作者必须持有有效 IP 授权，并在授权期限、地区、场景、商业化权限、二创权限和内容类型范围内创作。

### 8.2 作品提交字段

- 作品名称、作品类型、作品简介和创作说明；
- 预览图、视频或其他展示文件；
- 源文件和创作素材；
- 版权声明；
- 关联 IP、授权方案、合同和授权记录。

创作者必须确认：作品由本人或本主体创作；使用的 IP 和素材来自有效授权；未使用未授权第三方素材；不侵犯他人著作权、商标权、肖像权或其他权益；对提交内容真实性和合法性负责。

### 8.3 审核流程

```text
创作者提交
→ 文字敏感内容检测
→ 版权初审
→ 合规复核
→ 确权处理
→ 作品确权
```

版权/合规人员可以通过、退回补充材料或驳回。作品通过后生成确权编号、权益节点、文件 Hash 和真实存证记录。

作品没有草稿功能；未提交内容不保存。提交后不能直接修改，退回后修改并重新提交。

## 9. 商品创建与消费者商品商城

### 9.1 商品创建

创作者必须使用有效授权 IP，并关联已审核通过的二创作品后才能创建商品。一个商品只能绑定一个原始 IP，但一个作品可以关联多个商品。

商品字段：商品名称、简介、封面图、详情图、商品类型、商品版权说明、售后模板、销售地区、履约方式、SKU、售价和库存。

商品支持：

- 一个商品一个默认 SKU；
- 多规格时建立多个商品 SKU；
- 库存按 SKU 管理；
- 价格按 SKU 管理；
- 商品订单、发货、退货和售后关联具体 SKU；
- 当前版本由平台统一发货；创作者自行发货作为后续扩展能力；
- 创作者设置固定运费或免运费；
- 商品销售地区可指定地区或全国，只影响 H5 展示和筛选，不限制消费者购买；
- 消费者可跨地区购买；
- 商品详情仅展示商品信息、SKU、配送/售后规则和通俗版权说明；不展示创作者/品牌或 IP 信息。

一期商品不支持优惠券、满减、会员价和其他复杂营销。

### 9.2 商品自动发布

商品不经过平台管理员或履约客服人工审核。创作者提交后，系统自动校验：

- IP和授权状态；
- 授权期限、地区、场景和内容类型；
- 是否允许商业化和商品创作；
- 是否关联已审核作品；
- 商品文字与关联图片的敏感内容；
- 商品 SKU、售价、库存、运费和版权说明完整性。

文字与图片检测 `PASS/REVIEW` 后进入版权初审，初审通过进入合规复核，仅复核通过才 `PUBLISHED`；检测拦截或接口异常进入 `CHECK_REJECTED/CHECK_ERROR`，不进入人工待办，创作者修改后重新提交。

商品发布后，普通内容修改需要重新提交系统校验；新版本通过校验后自动发布。历史订单保存下单时的商品、SKU、价格、运费、地区和售后规则快照。

### 9.3 消费者商品商城

支持筛选：商品名称/关键词、商品地区、商品类型、价格区间；支持最新上架、价格从低到高、价格从高到低。不提供 IP、创作者或品牌筛选和展示。

地区只影响展示：选择某地区时显示该地区商品和全国商品，消费者不受地区限制购买。库存不足商品仍可展示，但不能下单。

商品详情页采用选项卡：商品详情、规格库存、配送说明、售后规则、版权说明。提交订单前，消费者需要确认相关规则。

## 10. 文旅活动创建与预约

### 10.1 活动创建

创作者可以直接基于已购买且有效的 IP 授权创建文旅活动，不强制先提交二创作品。一个活动只能绑定一个原始 IP。

活动字段：活动名称、简介、详情图、活动地点、地图点位、实际举办地区、活动日期、场次、票种、价格、预约上限、取消/退款模板、注意事项和版权说明。

规则：

- 活动必须指定实际举办地区，不能设置全国；
- 一个活动支持多个场次和多个票种；
- 预约名额按场次和票种独立控制；
- 支持收费票和免费票；
- 活动发布后不能修改名称、地点、日期、场次、票种、价格、预约上限和规则；
- 如未有人报名，可以下架并重新创建；
- 已有人报名不能下架，只能暂停后续报名；
- 暂停和恢复报名均由系统根据创作者提交的操作执行并记录，已报名消费者由创作者线下联系；
- 不支持改期申请；
- 活动取消和退款规则由平台固定模板提供，创作者只能选择不能自由修改。

### 10.2 活动自动发布

活动不经过平台管理员或履约客服人工审核。系统自动校验 IP 授权状态、期限、地区、场景、内容类型、活动字段、票种/场次规则和所有提交文字的第三方敏感内容检测。

校验通过后自动发布；检测不通过、疑似风险或接口异常时禁止发布，创作者修改后重新提交。

### 10.3 消费者预约

消费者 H5 活动详情页采用选项卡：活动详情、场次票种、活动地点、预约规则、取消/退款规则、版权说明。

消费者可以跨地区预约，但必须前往活动指定地点。提交预约前确认规则，预约成功后生成预约订单和电子核销码。

名额规则：提交预约时锁定名额；支付成功或免费预约成功后正式占用；未支付、支付失败或订单关闭后释放；取消或退款成功后按规则恢复；已核销不恢复。

未到场未核销的订单不退款，活动结束后标记为已过期，不触发活动完成分账。

## 11. 订单、支付与履约

### 11.1 订单类型

- IP授权订单：`AUTH-年月-流水号`；
- 商品订单：`ORD-年月-流水号`；
- 文旅预约订单：`BOOK-年月-流水号`；
- 售后单：`AFTER-年月-流水号`；
- 退款单：`REFUND-年月-流水号`；
- 分账记录：`SHARE-年月-流水号`。

订单号全局唯一、生成后不可修改，并关联合同、物流、售后、退款、分账和存证记录。

### 11.2 支付

- 测试环境可使用模拟支付；生产环境必须接入真实支付服务。数字人民币不是一期前置支付渠道，但需预留后续接入能力；
- 商品、活动和 IP 授权均采用商城订单模式；
- 提交后进入待支付；
- 微信支付成功回调或主动查单确认成功后进入已支付；
- 失败、取消或超时进入关闭；
- 待支付订单30分钟未支付自动关闭；
- IP授权订单关闭释放授权名额；商品订单关闭释放库存；活动订单关闭释放预约名额；
- 保存支付流水号、支付方式、支付状态和支付时间；
- 后续接入数字人民币时只替换支付适配接口。

### 11.3 商品物流

- 一期只支持物流配送，不支持到店自提和线下取货；
- 当前版本固定平台统一发货；创作者自行发货待后续开放；
- 运费支持创作者承担或消费者承担；
- 创作者设置固定运费或免运费；
- 真实对接物流服务，保存物流公司、运单号、发货主体、发货时间、轨迹、签收状态和履约凭证；
- 消费者在订单详情查看订单号、商品、SKU、收货地址、发货主体、物流信息和售后入口；
- 后续启用创作者自行发货时，仅可查看自己商品的待发货订单，收货信息按权限脱敏展示。

### 11.4 活动核销

- 履约客服负责现场核销；
- 核销码在支付成功或免费预约成功后生成；
- 核销成功后变为已使用，不能重复核销；
- 核销记录活动、场次、票种、预约单号、核销人员、时间和地点；
- 核销成功后预约订单完成并触发自动分账。

## 12. 售后与退款

### 12.1 商品退货退款

- 支持退货退款；
- 不支持换货、补发和维修；
- 已支付未发货可以申请取消/退款；
- 已发货只能走退货退款；
- 退货地址由履约方式决定：创作者发货使用创作者地址，平台发货使用平台地址；
- 售后固定模板由平台提供，创作者不能自由编写或发布后修改；
- 商品质量、错发、漏发由创作者或平台承担退货费用；消费者个人原因由消费者承担；
- 消费者提交申请并上传凭证、退货物流单号；
- 履约客服审核申请、确认收货和退款条件；
- 财务复核退款金额并调用微信支付退款，生成退款流水；
- 系统生成分账冲销记录；
- 特殊异常或争议由平台管理员处理。

### 12.2 文旅活动取消/退款

- 支持取消预约和退款；
- 不支持改期申请；
- 规则采用平台固定模板，创作者只能选择；
- 活动发布后不能修改取消/退款规则；
- 已核销不能取消或退款；
- 未到场未核销不退款；
- 消费者通过 H5 提交申请，履约客服受理，财务复核后调用微信支付退款；
- 特殊情况由平台管理员处理。

### 12.3 售后状态

消费者可在 H5 查看售后单号、关联订单、售后类型、申请时间、当前状态、退货地址、退货物流单号、退款金额、退款流水号和分账冲销状态。

状态示例：待审核、退货中、待确认、退款处理中、已完成、已驳回。

## 13. 自动分账与结算

### 13.1 普通授权分账方

- 原始 IP 权益方；
- 当前创作者；
- 城市运营；
- 平台服务费。

城市运营不参与商品/活动创作和审核，但保留 IP 所属城市的收益分成。

### 13.2 分账计算

- 订单实际成交金额作为分账基数；
- 运费不纳入收益分账；
- 退款按实际退款金额同比例冲销；
- 部分退款只冲销对应商品或票种；
- 金额保留到分，四舍五入差额归入平台服务费；
- 保存订单金额、退款金额、分账基数、比例快照、应分金额、实分金额和冲销金额。

### 13.3 结算流程

```text
商品订单完成或活动核销完成
→ 系统自动计算分账
→ 生成分账明细
→ 财务复核
→ 财务确认结算批次
→ 线下付款
→ 上传付款凭证
→ 记录付款状态
```

商品订单完成条件：物流签收且消费者确认收货；消费者未操作时，签收并经过售后保护期自动完成。售后、退款或投诉中的订单暂不完成，分账金额冻结。

文旅活动订单：现场核销成功后完成。未核销不触发活动完成分账。

独家买断后的商品和活动不产生后续二传收益分账，也不收取后续平台服务费。

## 14. 文件、存证与归档

### 14.1 文件权限

私有文件包括版权证明、评估报告、授权委托书、合同、作品源文件、素材包和售后凭证。

- 有权限的后台角色和对应创作者按范围查看；
- 消费者只能查看商品图、活动图和通俗版权说明；
- 素材包只对已生效授权创作者开放；
- 下载使用临时授权链接，不暴露长期真实地址；
- 下载记录包含文件编号、版本、人员、时间、IP地址和结果；
- 文件上传后生成 Hash。

### 14.2 真实存证对象

- IP版权证明和确权材料；
- 评估报告、授权委托书；
- 授权合同、授权凭证和授权边界快照；
- 创作者作品提交材料和确权结论；
- 商品/活动发布凭证；
- 订单、物流、核销、售后和退款关键凭证；
- 买断订单和买断费用分配记录。

链平台尚未确定，一期先完成可替换的链上适配层；不得伪造上链成功。保存链平台、存证编号、交易/回执编号、Hash、上链时间、状态和失败重试记录。

### 14.3 消费者展示

消费者 H5 不展示链上技术信息、版权证明原件、评估报告、合同、分账比例或内部审核意见，只展示通俗版权说明文字。

## 15. 敏感内容检测

- 平台所有用户主动提交或录入的文字信息，均调用第三方敏感内容检测接口；
- 覆盖 IP、授权说明、作品、商品、活动、售后、退款、审核备注、财务备注和其他表单文本；
- 系统固定按钮、字段标题和状态名称不重复检测；
- 系统根据用户输入生成的合同、通知和说明，生成前也要检测；
- 一期不做图片 OCR、视频和音频检测；仅 CNT-02 商品对已关联图片做同步内容审核，其他模块仍只检测文字；
- 检测结果：通过、疑似风险、不通过；
- 商品和活动疑似风险或不通过均禁止发布，退回创作者修改，不进入人工复核；
- 作品疑似风险可以进入版权/合规人工复核；
- 接口异常或超时禁止提交或发布；
- 修改文字后必须重新检测；
- 保存检测结果、分类、接口流水号和时间，不保存第三方返回的敏感原文。

## 16. 消费者 H5 规则

### 16.1 游客访问

- 未登录可浏览首页、公开商品、活动和详情；
- 未登录可以加入商品购物车；
- 结算、购买、预约、查看订单、核销码、售后和个人中心时要求登录；
- 游客购物车使用 Cookie 保存30天，只保存 SKU、数量和加入时间；
- 登录后将 Cookie 购物车合并到消费者账号；
- 购物车不占库存，结算时重新校验库存、价格和商品状态。

### 16.2 地区筛选

- 首次进入默认“全部地区”；
- 地区选择只影响商品展示和筛选；
- 选择某地区时显示该地区商品和全国商品；
- 消费者不受地区限制购买；
- 活动展示实际举办地区，消费者可以跨地区预约；
- 保存消费者上次选择的地区。

### 16.3 H5页面

首页、IP公开介绍、商品商城、商品详情、购物车、订单确认、微信支付、订单详情、物流、活动列表、活动详情、预约确认、核销码、取消/退款、售后、个人中心。

商品和活动详情页使用选项卡展示详情、规格/场次、配送/地点、售后/取消退款、版权说明等内容。消费者只看到通俗版权说明。

## 17. 权限、安全与审计

日志覆盖：登录、注册、验证码、实名、账号状态、IP、授权、合同、作品、商品、活动、订单、支付、发货、核销、售后、退款、分账、结算、文件上传下载、导出和上链。

每条日志至少记录操作人、角色、时间、IP地址、对象编号、操作前后状态和结果。普通角色不能删除或修改审计日志。

敏感数据包括实名资料、身份证信息、企业主体资料、授权委托书、收款账户、收货信息和版权材料。按最小权限展示，消费者和普通业务角色只能查看脱敏信息。

一期不支持用户自行注销账号或删除历史业务数据。订单、合同、实名、结算和存证相关数据长期留存。

## 18. 一期验收标准

一期 MVP 必须满足：

1. 城市运营可以录入 IP，选择固定授权方案和分账方案，版权/合规可以完成确认。
2. IP 可以以商城形式展示，创作者可以注册、实名、购买授权并生成合同。
3. 授权名额、有效期、地区、场景和内容类型校验有效。
4. 创作者可以提交作品，作品经过版权/合规审核后确权。
5. 创作者可以基于已确权作品创建商品，也可以基于有效授权直接创建文旅活动。
6. 商品和活动文字经过第三方检测，授权边界自动校验，校验通过后自动发布。
7. 消费者可以浏览、加入购物车、通过微信支付购买商品和预约活动。
8. 商品可以物流配送，活动可以生成核销码并完成现场核销。
9. 商品支持退货退款，活动支持取消和退款，不支持改期。
10. 订单完成或活动核销后，系统自动计算普通授权分账；独家买断不产生后续二传分账。
11. 财务可以复核分账、确认结算并上传付款凭证。
12. 关键版权、授权、作品、发布、订单、履约和售后凭证完成真实存证或记录明确的上链失败状态。
13. 角色权限、敏感数据脱敏、文件访问、操作审计和导出留痕有效。
14. OpenAPI、数据库字段字典、状态机、测试记录、部署说明和验收记录齐备。

## 19. 仍需外部配置但不影响需求基线

以下内容属于实施配置，不作为重复需求确认项：

- 短信服务商及模板；
- 物流服务商及回调参数；
- 文件存储服务；
- 第三方个人/企业实名认证服务；
- 第三方敏感内容检测服务；
- 真实存证链平台；
- 平台客服电话；
- 取消/退款固定模板的具体时间参数；
- 授权方案和分账方案的具体金额、比例及名额。

这些配置确定后，应补充到 API 接口文档、数据库字典和部署配置文件中，不改变本文件已经确认的业务边界。
