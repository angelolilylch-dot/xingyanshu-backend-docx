# 账号密码生命周期与找回流程

## 1. 密码规则

- 长度 8–64 位，不允许空格、制表符和换行。
- 必须同时包含大写字母、小写字母、数字和特殊字符。
- 密码只以 bcrypt 哈希保存，接口、列表、详情和日志不得返回明文或哈希。

## 2. 新建账号与首次登录

平台管理员填写 `initialPassword` 创建账号；后端校验密码格式后写入哈希，并将 `mustChangePassword=true`。管理员线下通知账号使用人。使用人首次用初始密码登录后，响应带 `mustChangePassword=true`，前端必须跳转修改密码页；在修改完成前，其他后台接口统一返回 `428 AUTH_PASSWORD_CHANGE_REQUIRED`。提交 `POST /auth/password/change` 成功后标记为正常账号，再用新密码正常登录。

## 3. 管理员重置密码

平台管理员调用 `POST /admin/accounts/{userId}/password/reset` 提交 `newPassword`。后端更新密码哈希、设置 `mustChangePassword=true`，并线下通知使用人。使用人下次登录后必须按首次登录流程修改密码。

## 4. 短信找回密码

1. 使用人调用 `POST /auth/password-reset/sms/send` 提交已绑定手机号。
2. 系统向已启用后台账号发送一次性验证码；为避免枚举账号，即使手机号不存在也返回相同成功结构。
3. 使用人调用 `POST /auth/password-reset` 提交手机号、验证码和新密码。
4. 验证码一次性消费；密码更新成功后清除强制改密标记，之后可直接用新密码登录。

短信验证码有效期 5 分钟。当前开发环境返回 `mockCode` 便于联调，生产环境必须接入真实短信服务，不能返回验证码。

## 5. 接口清单

| 接口 | 权限 | 用途 |
|---|---|---|
| `POST /admin/accounts` | 平台管理员 | 创建账号并设置初始密码 |
| `POST /auth/login` | 公开 | 账号、密码、图形验证码登录；返回 `mustChangePassword` |
| `POST /auth/password/change` | 已登录账号 | 使用旧密码修改为新密码；首次登录必调 |
| `POST /admin/accounts/{userId}/password/reset` | 平台管理员 | 设置临时密码并强制目标账号改密 |
| `POST /auth/password-reset/sms/send` | 公开 | 发送找回密码短信验证码 |
| `POST /auth/password-reset` | 公开 | 通过短信验证码设置新密码 |
