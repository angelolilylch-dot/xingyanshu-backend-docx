# 星衍树全项目短信模板清单与变量规范 v1.0

> 版本：v1.0｜整理日期：2026-10-14  
> 适用范围：星衍树后台、创作者端、消费者 H5、独立 `AVATAR_H5`（个人数字形象 IP 库）。  
> 使用原则：本清单区分“当前代码已存在的验证码入口”“已确认但待接入的通知”和“后续业务建议”。模板文案可提交短信服务商审核，但模板 ID、签名和服务商配置不得写入前端代码或仓库。

## 1. 短信签名与通用规则

- 推荐签名：`【星衍树】`。实际签名须以主体资质审核结果为准。
- 验证码一律为 6 位数字；单次有效期 5 分钟；同手机号、同场景建议 60 秒内仅可重发 1 次。
- 验证码仅用于本人操作校验，不得包含身份证号、实名结果、照片/视频、完整收货地址、支付金额、访问令牌或对象存储链接。
- 验证成功后应一次性失效；连续错误、异常 IP 或设备需触发限流/风控。
- 营销内容、广告链接和业务验证码必须使用不同模板及不同发送场景。
- 生产环境只允许真实短信服务商；测试验证码、Mock 返回值或服务商密钥不得出现在生产响应、模板或日志中。

## 3. 已有验证码入口

### 3.1 后台密码找回验证码

| 项目 | 内容 |
| --- | --- |
| 模板编码 | `XYS_AUTH_PASSWORD_RESET` |
| 对应接口 | `POST /api/v1/auth/password-reset/sms/send` |
| 触发条件 | 后台账号主动发起密码找回 |
| 变量 | `${code}`、`${minutes}` |
| 建议文案 | `【星衍树】您正在进行后台账号密码重置，验证码为${code}，${minutes}分钟内有效。非本人操作请忽略。` |
| 发送限制 | 5 分钟有效；建议 60 秒重发间隔、单日频控和失败审计 |

### 3.2 消费者 H5 登录验证码

| 项目 | 内容 |
| --- | --- |
| 模板编码 | `XYS_CONSUMER_LOGIN` |
| 对应接口 | `POST /api/v1/consumer/auth/sms/send` |
| 触发条件 | 消费者以手机号登录消费者 H5 |
| 变量 | `${code}`、`${minutes}` |
| 建议文案 | `【星衍树】您正在登录消费者服务，验证码为${code}，${minutes}分钟内有效。非本人操作请勿泄露验证码。` |
| 边界 | 仅用于 `CONSUMER_H5` 会话，不与后台、创作者或 `AVATAR_H5` 共用。 |

### 3.3 创作者注册验证码

| 项目 | 内容 |
| --- | --- |
| 模板编码 | `XYS_CREATOR_REGISTER` |
| 对应接口 | `POST /api/v1/creator/auth/sms/send` |
| 触发条件 | 创作者首次注册并绑定手机号 |
| 变量 | `${code}`、`${minutes}` |
| 建议文案 | `【星衍树】您正在注册创作者账号，验证码为${code}，${minutes}分钟内有效。非本人操作请忽略。` |
| 边界 | 仅用于注册校验；创作者主体实名核验属于第三方实名能力，不在短信中透露核验结果。 |

### 3.4 个人数字形象 IP 库 H5 登录验证码

| 项目 | 内容 |
| --- | --- |
| 模板编码 | `XYS_AVATAR_LOGIN` |
| 对应接口 | `POST /api/v1/avatar/auth/sms/send`，场景固定 `AVATAR_LOGIN` |
| 触发条件 | 入库者登录独立 `AVATAR_H5` |
| 变量 | `${code}`、`${minutes}` |
| 建议文案 | `【星衍树】您正在登录个人数字形象建档服务，验证码为${code}，${minutes}分钟内有效。非本人操作请忽略。` |
| 边界 | 登录后仍须第三方实名，且实名姓名、手机号、性别须与同城名单一致；短信不得说明任何一项是否匹配。 |

## 4. 已确认的数字形象业务通知

### 4.1 建档邀请

| 项目 | 内容 |
| --- | --- |
| 模板编码 | `XYS_AVATAR_INVITE` |
| 触发条件 | 城市运营者向已导入名单人员发起建档提醒 |
| 变量 | `${city_name}`、`${entry_url}`、`${support_phone}` |
| 建议文案 | `【星衍树】您受邀进行${city_name}个人数字形象建档，请通过${entry_url}完成登录、实名和资料采集。如需协助请联系${support_phone}。` |
| 约束 | 链接仅为城市通用入口，不绑定某个人；不包含名单、实名或素材信息。 |

### 4.2 档案归档完成

| 模板编码 | `XYS_AVATAR_ARCHIVED` |
| 变量 | `${city_name}`、`${retention_date}` |
| 建议文案 | `【星衍树】您的个人数字形象档案已完成归档，资料将保存至${retention_date}。您可在建档 H5 查看状态或申请删除。` |

### 4.3 补采提醒

| 模板编码 | `XYS_AVATAR_RESUBMIT` |
| 变量 | `${entry_url}`、`${deadline}`、`${support_phone}` |
| 建议文案 | `【星衍树】您的个人数字形象资料需要补采，请于${deadline}前通过${entry_url}完成操作。如需协助请联系${support_phone}。` |
| 约束 | 不通过短信透露具体人脸、视频或风控原因。 |

### 4.4 删除申请处理通知

| 模板编码 | `XYS_AVATAR_DELETE_PROGRESS` |
| 变量 | `${status_text}`、`${support_phone}` |
| 建议文案 | `【星衍树】您提交的个人数字形象档案删除申请当前状态：${status_text}。如需协助请联系${support_phone}。` |
| 可用状态 | `已受理`、`已完成`、`因法定保留暂不能删除`；不得在短信中写入内部审核人或敏感原因。 |

## 6. 服务商对接字段

| 内部字段 | 说明 |
| --- | --- |
| `templateCode` | 本文模板编码；由服务端映射至供应商模板 ID。 |
| `mobile` | 接收手机号；日志及审计只保存脱敏值或哈希。 |
| `params` | 模板变量键值对；仅传该模板白名单变量。 |
| `bizType` / `bizId` | 业务归属，例如 `AVATAR_PROFILE`、`PRODUCT_ORDER`；便于审计和重试。 |
| `providerRequestNo` | 短信服务商请求流水。 |
| `status` | `PENDING/SENT/DELIVERED/FAILED/CANCELLED`。 |
| `idempotencyKey` | 通知类发送须防重复；验证码以手机号、场景和频控为主。 |

## 7. 上线前验收清单

- [ ] 短信签名、模板文案、变量数量和变量类型已通过服务商审核。
- [ ] 服务商密钥仅由部署环境变量或密钥管理系统提供。
- [ ] 四类验证码均完成：发送成功、频控、验证码错误、过期、一次性使用、服务商失败重试测试。
- [ ] 消费者、创作者、后台、`AVATAR_H5` 的验证码缓存键和会话隔离已验证。
- [ ] 邀请、归档、补采、删除、履约等通知均具备业务幂等、发送记录与人工重发审计。
- [ ] 生产响应、日志、前端页面和 AI 交付包中不存在测试验证码、服务商密钥或永久下载链接。
