# 星衍树版权二创平台一期 MVP 业务状态机与流转规则

版本：v0.4  
状态：已确认需求基线的实施规则  
关联基线：[一期MVP需求基线与范围说明.md](一期MVP需求基线与范围说明.md)

## 1. 目的、边界与约定

本文件把一期 MVP 已确认的业务规则转换为可用于数据库枚举、接口校验、前端展示、测试用例和审计日志的状态机定义。若本文件与《一期MVP需求基线与范围说明》存在冲突，以需求基线为准；发现冲突后应先更新本文件，不得直接以代码行为替代业务规则。

### 1.1 通用约定

- 每个业务对象必须同时保存：当前状态、上一次状态、状态变更时间、触发方式、触发人或系统任务、原因/备注、关联业务编号。
- 状态变更必须写入不可修改的审计日志；日志记录操作人、角色、对象编号、前后状态、时间、客户端 IP、结果和失败原因。
- 只有本文列出的流转可以发生。接口收到非法状态流转时，返回业务错误，不得静默覆盖状态。
- “自动”是由系统任务或接口回调触发，仍须记录为系统操作；“人工”是由有权限的角色明确提交。
- 用户主动提交的全部文字字段先经过第三方敏感内容检测。检测接口超时、异常、返回失败或疑似风险时，默认采取阻断策略，不得发布或进入下一业务环节。
- 金额、价格、分账比例、合同、授权范围、商品 SKU、活动票种、售后规则均须在关键节点生成快照。后续配置变化不影响历史记录。
- “已关闭”“已驳回”“已失效”“已取消”等终态原则上不可回退；需要重新办理时，创建新申请、新版本或新订单。

### 1.2 状态字段设计建议

每张核心业务表至少具备下列字段：

| 字段 | 说明 |
| --- | --- |
| `status` | 当前主状态，使用固定枚举 |
| `status_reason_code` | 状态原因编码，如超时、检测不通过、资料缺失 |
| `status_reason` | 面向角色显示的说明，敏感检测不保存原始命中词 |
| `status_changed_at` | 最近状态变更时间 |
| `status_changed_by_type` | `USER`、`SYSTEM`、`THIRD_PARTY` |
| `status_changed_by_id` | 操作人、系统任务或第三方服务标识 |
| `version` | 乐观锁版本号，防止并发重复处理 |
| `snapshot_version` | 引用的规则、合同或配置快照版本 |

### 1.3 敏感内容检测通用子状态

敏感内容检测是表单提交的通用子流程，不应与 IP、作品、商品等主业务状态混淆。每次提交或重新提交均生成一条检测记录。

| 检测状态 | 含义 | 后续动作 |
| --- | --- | --- |
| `PENDING` | 已提交，等待调用检测服务 | 系统发起检测 |
| `CHECKING` | 检测服务处理中 | 禁止进入下一环节 |
| `PASSED` | 文本检测通过 | 进入对应主流程 |
| `SUSPECTED` | 检测为疑似风险 | 作品进入人工复核；商品、活动等直接禁止提交并退回修改 |
| `REJECTED` | 检测不通过 | 禁止提交并退回修改 |
| `ERROR` | 接口异常、超时或结果不可用 | 禁止提交并退回修改，可由用户重新提交 |

检测记录仅保存检测服务、请求编号、结果类别、时间、对象编号和必要的脱敏说明；不保存或向普通角色展示原始敏感词命中内容。

## 2. 账号与实名认证状态机

### 2.1 创作者账号状态

账号状态和实名认证状态分开保存。账号可用不代表已实名；只有账号可用且实名认证为 `VERIFIED` 时才可购买授权、下载素材和创建内容。

| 账号状态 | 枚举建议 | 含义 |
| --- | --- | --- |
| 正常 | `ACTIVE` | 可以登录并在权限范围内操作 |
| 已停用 | `SUSPENDED` | 平台管理员暂停，不能登录、购买或创建内容；历史记录保留 |

| 当前状态 | 触发方 | 条件 | 目标状态 | 联动与限制 |
| --- | --- | --- | --- | --- |
| 未创建 | 创作者 | 注册信息、短信/图形验证通过 | `ACTIVE` | 建立账号，实名认证初始为 `UNVERIFIED` |
| `ACTIVE` | 平台管理员 | 存在合规、账号安全或运营管理理由 | `SUSPENDED` | 强制退出登录；禁止新增购买、上传、提交、下载和发货操作；不删除历史数据 |
| `SUSPENDED` | 平台管理员 | 停用原因已处理 | `ACTIVE` | 恢复权限；不自动恢复已过期或已解除的授权 |

### 2.2 创作者实名认证状态

| 实名状态 | 枚举建议 | 含义与权限 |
| --- | --- | --- |
| 未认证 | `UNVERIFIED` | 可浏览创作者 IP 商城，不能购买授权或创建内容 |
| 认证中 | `VERIFYING` | 已向第三方提交核验，仍不能购买或创建内容 |
| 已认证 | `VERIFIED` | 满足主体认证前置条件；个人、企业、工作室均可购买授权 |

| 当前状态 | 触发方 | 条件 | 目标状态 | 说明 |
| --- | --- | --- | --- | --- |
| `UNVERIFIED` | 创作者 | 提交个人或企业/工作室实名资料 | `VERIFYING` | 调用第三方实名接口 |
| `VERIFYING` | 第三方/系统 | 核验成功 | `VERIFIED` | 保存核验服务、时间和结果编号；不允许用户自行修改主体资料 |
| `VERIFYING` | 第三方/系统 | 核验失败、超时或不可用 | `UNVERIFIED` | 保存失败类别和脱敏原因，可重新发起认证 |

企业/工作室可留存授权委托书，状态仅表示资料状态：`NOT_REQUIRED`（个人不适用）或 `FILED`（已留存）。委托书不参与实名认证状态流转、不需要平台确认，也不影响购买授权资格。

### 2.3 消费者账号状态

消费者使用手机号和短信验证码注册、登录。手机号为唯一账号，不设置密码，不支持一期内自助换绑手机号。消费者账号使用统一的 `ACTIVE` / `SUSPENDED` 状态；停用后不能下单、预约或申请售后，既有订单和售后仍保留供后台处理。

## 3. 授权方案状态机

授权方案是平台固定配置，可复用到多个 IP。一个 IP 一期只能绑定一个当前有效方案。

| 状态 | 枚举建议 | 含义 |
| --- | --- | --- |
| 草稿 | `DRAFT` | 平台管理员编辑中，不能被 IP 选择 |
| 待版权/合规审核 | `PENDING_COMPLIANCE` | 提交给版权/合规人员审核 |
| 已退回 | `RETURNED` | 审核退回修改，不能被 IP 选择 |
| 已确认 | `CONFIRMED` | 内容已获确认，等待管理员启用 |
| 已启用 | `ENABLED` | 可被城市运营选择并绑定至 IP |
| 已停用 | `DISABLED` | 不可被新 IP 选择；仅未绑定 IP 的方案可进入该状态 |

| 当前状态 | 触发方 | 条件 | 目标状态 | 禁止/联动 |
| --- | --- | --- | --- | --- |
| `DRAFT` / `RETURNED` | 平台管理员 | 方案字段完整，文本检测通过 | `PENDING_COMPLIANCE` | 生成待审版本 |
| `PENDING_COMPLIANCE` | 版权/合规 | 方案合法、边界完整 | `CONFIRMED` | 固化审核意见 |
| `PENDING_COMPLIANCE` | 版权/合规 | 需要补充或修改 | `RETURNED` | 填写退回原因 |
| `CONFIRMED` | 平台管理员 | 确认启用 | `ENABLED` | 允许被 IP 选择 |
| `ENABLED` | 平台管理员 | 没有任何已绑定 IP | `DISABLED` | 停用后不可新选用 |
| `DISABLED` | 平台管理员 | 重新确认启用且无历史修改 | `ENABLED` | 仅恢复原方案可用性 |

**锁定规则：** 方案一旦被任一 IP 绑定，即标记 `is_bound = true`，不得修改、删除或停用。需要改变期限、地区、场景、内容类型、名额、授权方式或分配规则时，必须新建方案或新版本；授权方案不承载 IP 交易价格。IP 的建议交易价在确权时锁定，历史合同继续引用下单时价格快照。

## 4. IP 入库、确权与商城上架状态机

### 4.1 IP 主状态

| 状态 | 枚举建议 | 含义 |
| --- | --- | --- |
| 草稿 | `DRAFT` | 城市运营录入中，未提交，不对外展示 |
| 待版权/合规审核 | `PENDING_COMPLIANCE` | 已提交权利证明、展示资料、方案选择和分配方案 |
| 补充材料 | `SUPPLEMENT_REQUIRED` | 版权/合规退回，等待城市运营补充 |
| 已上架 | `LISTED` | 可在创作者 IP 商城展示和购买 |
| 暂停授权 | `PAUSED` | 暂停新购买，不影响历史授权的查阅与已产生订单处理 |
| 已下架 | `DELISTED` | 主动停止新购买，不参与商城展示 |
| 已失效 | `EXPIRED` | 权利材料、IP 或方案期限到期，停止新购买 |

| 当前状态 | 触发方 | 条件 | 目标状态 | 联动与限制 |
| --- | --- | --- | --- | --- |
| `DRAFT` / `SUPPLEMENT_REQUIRED` | 城市运营 | 字段、证明文件、**完整素材包**、固定方案和分配方案完整，DCI 状态为 `UPLOADED`，文本检测通过 | `PENDING_COMPLIANCE` | 主归属城市和唯一原始权利人必须已确定；`MISSING` 或 `ASSISTANCE_REQUESTED` 时不得提交；素材包文件 Hash 与清单 Hash 必须已固定 |
| `PENDING_COMPLIANCE` | 版权/合规 | 权属和授权边界审核通过，DCI 证书核验通过，方案/商城资料完整、建议交易价已确认且 IP 关键材料与**素材包清单**存证成功 | `LISTED` | DCI 状态更新为 `VERIFIED`；生成确权结论、授权绑定，锁定建议交易价和商城可见状态，并将素材包置为 `FROZEN` |
| `PENDING_COMPLIANCE` | 版权/合规 | 资料不足或边界不清 | `SUPPLEMENT_REQUIRED` | 返回明确补充项；不得直接上架 |
| `LISTED` | 平台管理员 | 运营暂停或风险处置 | `PAUSED` | 停止新购买，隐藏商城购买入口 |
| `PAUSED` | 平台管理员 | 风险解除且材料、方案仍有效 | `LISTED` | 恢复新购买 |
| `LISTED` / `PAUSED` | 平台管理员 | 主动停止授权销售 | `DELISTED` | 停止新购买；历史授权不受影响 |
| `LISTED` / `PAUSED` | 系统 | IP、权利材料或授权方案到期 | `EXPIRED` | 自动隐藏；停止新购买 |
| `DELISTED` | 平台管理员 | 重新上架前置条件仍完整有效 | `LISTED` | 重新参与商城展示 |

### 4.2 上架与商城展示规则

- DCI 独立状态：`MISSING`（未上传）、`ASSISTANCE_REQUESTED`（已申请代办）、`UPLOADED`（已上传待核验）、`VERIFIED`（已核验）、`REJECTED`（核验不通过）。城市运营可在 `MISSING` 或 `ASSISTANCE_REQUESTED` 时保存 IP 草稿；只有 `UPLOADED` 才可提交审核，只有 `VERIFIED` 才可确权并自动上架。
- 城市运营申请 DCI 代办时，系统先固化 DCI 提交包及素材包清单 Hash，并锁定该次提交包。平台管理员的代办处理不代替版权/合规核验证书；代办中不得提交审核、确权、上架、购买或下载。需要补正时必须退回/终止当前代办请求、重新生成清单 Hash 并新建代办请求，不得原地修改已锁定提交包。
- 素材包独立状态为 `DRAFT` → `EVIDENCE_PENDING` → `EVIDENCED` → `FROZEN`。仅当 DCI 为 `VERIFIED`、IP 确权通过且 IP 关键材料与素材包清单存证均为 `SUCCESS` 时，才可将素材包冻结并使 IP 进入 `LISTED`。`FROZEN` 后原 IP 与所有入库素材不可修改、删除、替换、追加或版本覆盖；新增或修正素材必须新建 IP 入库/确权记录。
- DCI 代办申报包、素材包清单、冻结后的交付与下载等业务动作，以《业务流程与关键规则》为准；本文件只维护其状态前置与迁移要求。
- 仅 `LISTED` 且存在可购买名额的普通授权 IP 可正常展示和购买。
- `PAUSED`、`DELISTED`、`EXPIRED`、售罄 IP 均不参与正常商城展示；不得以“可购买但不可提交”的方式保留入口。
- 独家买断 IP 在独家买断订单生效后，IP 状态保持历史可查，但商城可见性变为隐藏，且不再允许任何新购买。
- 一个 IP 的主归属城市确权后不可直接改动；需要纠错时作为平台管理员的异常处理流程，保留原值、变更理由和审计证据。

### 4.3 IP 强制风险处置

当出现虚假资料、越权使用、侵权或重大合规风险时，平台管理员可发起风险处置，版权/合规确认后执行：

1. IP 转为 `PAUSED`，停止新的授权购买；
2. 受影响的有效授权转为 `REVOKED`；
3. 未产生订单的商品停止销售、活动停止新增预约；
4. 未完成商品订单和未核销活动由平台管理员记录“继续履约”或“退款处理”决定；
5. 对应未结算分账转为冻结；
6. 所有决定、证据、通知和存证均须留痕。

## 5. 创作者 IP 授权订单、合同与授权记录状态机

### 5.1 授权订单状态

| 状态 | 枚举建议 | 含义 |
| --- | --- | --- |
| 待支付 | `PENDING_PAYMENT` | 已确认合同条款并创建订单，暂锁定授权名额 |
| 已支付 | `PAID` | 模拟支付成功，等待授权生效事务完成 |
| 已关闭 | `CLOSED` | 支付失败、用户取消或超时，订单终止 |
| 已完成 | `COMPLETED` | 授权、合同、凭证、快照均已生成且授权记录已生效 |

| 当前状态 | 触发方 | 条件 | 目标状态 | 联动 |
| --- | --- | --- | --- | --- |
| 无订单 | 创作者 | 账号正常、实名认证合格、IP 已上架、名额可用、未购买过该 IP、勾选合同 | `PENDING_PAYMENT` | 锁定一个授权名额；写入订单、方案、价格和合同条款快照 |
| `PENDING_PAYMENT` | 创作者/系统 | 用户取消、支付失败或 30 分钟未支付 | `CLOSED` | 释放授权名额；不生成有效合同和授权 |
| `PENDING_PAYMENT` | 模拟支付适配器 | 支付成功 | `PAID` | 保存支付流水、支付时间和方式 |
| `PAID` | 系统 | 授权记录、虚拟合同、授权凭证、范围快照生成成功并提交存证 | `COMPLETED` | 授权记录转为 `ACTIVE`；买断场景立即隐藏 IP |

支付成功后不支持用户取消或退款。`PAID` 到 `COMPLETED` 必须在同一可靠事务/补偿任务中完成，防止已扣名额但未生成授权。

### 5.2 授权记录状态

| 状态 | 枚举建议 | 含义 |
| --- | --- | --- |
| 生效中 | `ACTIVE` | 可下载素材、创建合规范围内的作品/商品/活动 |
| 已到期 | `EXPIRED` | 授权期限自然结束，不能续期 |
| 已解除 | `REVOKED` | 因风险、侵权或重大合规原因强制解除 |

| 当前状态 | 触发方 | 条件 | 目标状态 | 联动 |
| --- | --- | --- | --- | --- |
| 无记录 | 系统 | 授权订单 `PAID` 后所有合同资料生成完成 | `ACTIVE` | 开放素材下载和范围内创作权限 |
| `ACTIVE` | 系统定时任务 | 到达授权有效期结束时间 | `EXPIRED` | 停止新下载、创建、销售和预约；历史合同/订单/结算可查 |
| `ACTIVE` | 平台管理员发起 + 版权/合规确认 | 虚假资料、越权、侵权或重大风险 | `REVOKED` | 执行第 4.3 节风险处置与资金冻结规则 |

`EXPIRED`、`REVOKED` 不可恢复，也不支持续期。授权到期后，原购买创作者可以按届时已上架、有效的新方案重新创建授权订单，生成新的合同、授权凭证和范围快照；这属于重新购买，不是续期。被强制解除的授权不允许自动恢复，是否允许再次购买由平台风险处置结论决定。

### 5.3 合同、凭证与素材包状态

| 对象 | 状态机 |
| --- | --- |
| 虚拟合同 | `GENERATING` → `EFFECTIVE`；生成异常为 `GENERATION_FAILED`，由系统补偿重试。合同生效后不可修改或删除。 |
| 授权凭证/范围快照 | `GENERATING` → `EFFECTIVE`；与合同同时引用订单与方案快照。 |
| 素材下载权限 | 仅授权 `ACTIVE`、素材包 `FROZEN` 且素材包存证 `SUCCESS` 时为 `AVAILABLE`；授权 `EXPIRED` / `REVOKED` 时为 `UNAVAILABLE`。已下载历史不删除，禁止生成新的下载临时链接。 |

## 6. 二创作品审核与确权状态机

作品必须绑定有效授权，且在授权范围内。作品没有草稿；未提交内容不保存。

| 状态 | 枚举建议 | 含义 |
| --- | --- | --- |
| 提交中 | `SUBMITTING` | 创作者提交文件和文本，尚未完成受理 |
| 文字检测中 | `TEXT_CHECKING` | 等待第三方检测 |
| 待版权初审 | `PENDING_COPYRIGHT_REVIEW` | 文本检测通过，等待版权初审 |
| 待合规复核 | `PENDING_COMPLIANCE_REVIEW` | 版权初审通过，等待合规复核 |
| 确权处理中 | `RIGHTS_REGISTERING` | 合规通过，生成确权结论、Hash 和存证 |
| 已确权 | `RIGHTS_CONFIRMED` | 可关联创建多个商品，也可作为作品资产查阅 |
| 退回补充 | `RETURNED` | 缺少材料或需修改，创作者重新提交新版本 |
| 已驳回 | `REJECTED` | 不符合版权/合规要求，当前版本终止 |
| 检测不通过 | `TEXT_REJECTED` | 文本检测失败，当前版本终止，创作者修改后新提交 |
| 检测异常 | `TEXT_CHECK_ERROR` | 检测异常，当前版本不可继续，可重新提交 |

| 当前状态 | 触发方 | 条件 | 目标状态 | 说明 |
| --- | --- | --- | --- | --- |
| 无版本 | 创作者 | 有效授权、字段/文件完整、声明已勾选 | `SUBMITTING` | 生成不可直接编辑的提交版本 |
| `SUBMITTING` | 系统 | 受理成功 | `TEXT_CHECKING` | 创建敏感内容检测记录 |
| `TEXT_CHECKING` | 系统 | 检测通过 | `PENDING_COPYRIGHT_REVIEW` | 分配版权初审队列 |
| `TEXT_CHECKING` | 系统 | 检测疑似风险 | `PENDING_COPYRIGHT_REVIEW` | 标记风险，版权/合规人员进行人工复核 |
| `TEXT_CHECKING` | 系统 | 检测不通过 | `TEXT_REJECTED` | 返回可理解的修改提示，不暴露敏感词原文 |
| `TEXT_CHECKING` | 系统 | 检测异常 | `TEXT_CHECK_ERROR` | 禁止流转；允许重新提交 |
| `PENDING_COPYRIGHT_REVIEW` | 版权/合规 | 权利材料、授权范围、创作声明符合 | `PENDING_COMPLIANCE_REVIEW` | 记录初审结论 |
| `PENDING_COPYRIGHT_REVIEW` | 版权/合规 | 需补充材料或修正 | `RETURNED` | 记录补充项 |
| `PENDING_COPYRIGHT_REVIEW` | 版权/合规 | 明确不符合 | `REJECTED` | 记录驳回原因 |
| `PENDING_COMPLIANCE_REVIEW` | 版权/合规 | 合规复核通过 | `RIGHTS_REGISTERING` | 生成确权数据 |
| `PENDING_COMPLIANCE_REVIEW` | 版权/合规 | 需补充或不通过 | `RETURNED` / `REJECTED` | 保留审核意见 |
| `RIGHTS_REGISTERING` | 系统 | Hash、确权结论、真实存证完成 | `RIGHTS_CONFIRMED` | 允许被商品关联 |

`RETURNED`、`REJECTED`、`TEXT_REJECTED`、`TEXT_CHECK_ERROR` 均不得直接回写原版本；创作者修改后生成新版本，并保留所有历史版本与审核轨迹。

## 7. 商品自动校验、发布与可售状态机

商品必须绑定一个有效 IP 授权和一件 `RIGHTS_CONFIRMED` 的二创作品。商品没有草稿功能；每次提交都是可追溯版本。

### 7.1 商品内容版本状态

| 状态 | 枚举建议 | 含义 |
| --- | --- | --- |
| 提交中 | `SUBMITTING` | 创作者已提交商品版本 |
| 自动校验中 | `AUTO_CHECKING` | 正在校验授权边界、字段、SKU 和文本检测 |
| 已发布 | `PUBLISHED` | 当前版本已自动通过并在 H5 展示 |
| 校验不通过 | `CHECK_REJECTED` | 授权、字段或文本不符合，禁止发布 |
| 校验异常 | `CHECK_ERROR` | 外部检测或系统校验异常，禁止发布 |
| 已下架 | `DELISTED` | 创作者或平台按权限停止销售 |

| 当前状态 | 触发方 | 条件 | 目标状态 | 联动与限制 |
| --- | --- | --- | --- | --- |
| 无版本 / 已发布版本修改 | 创作者 | 有效授权、已确权作品、完整 SKU/价格/库存/运费/售后规则 | `SUBMITTING` | 已发布商品修改创建新版本；旧版本继续服务历史订单 |
| `SUBMITTING` | 系统 | 受理成功 | `AUTO_CHECKING` | 校验授权状态、期限、地区、场景、内容类型、商业化权限、作品状态、SKU、价格、库存、运费、版权说明和所有提交文字 |
| `AUTO_CHECKING` | 系统 | 所有校验与文本检测通过 | `PUBLISHED` | 自动发布，不经过平台管理员或履约客服人工内容审核；生成发布凭证并存证 |
| `AUTO_CHECKING` | 系统 | 任一边界校验不通过、检测不通过或疑似风险 | `CHECK_REJECTED` | 禁止发布；返回脱敏修改原因 |
| `AUTO_CHECKING` | 系统 | 检测接口异常、超时或必要服务不可用 | `CHECK_ERROR` | 禁止发布；允许创作者重新提交 |
| `PUBLISHED` | 创作者/平台管理员风险处置 | 主动下架或授权失效/解除 | `DELISTED` | 停止新下单；历史订单继续履约或按风险决定处理 |
| `DELISTED` | 创作者 | 授权仍有效、当前版本重新校验通过 | `PUBLISHED` | 重新上架仍须走完整自动校验 |

商品的 `CHECK_REJECTED`、`CHECK_ERROR` 不进入任何人工发布审核队列。创作者只能修改后提交新版本；系统不通过内容即不得对消费者展示。

### 7.2 商品可售状态与 SKU 库存

商品发布状态与可售状态独立。发布状态决定是否可见；库存决定是否可以选择 SKU 并提交订单。

| SKU 状态 | 枚举建议 | 规则 |
| --- | --- | --- |
| 可售 | `ON_SALE` | 库存大于零，商品已发布，允许下单 |
| 已锁定 | `RESERVED` | 某待支付订单占用部分库存；库存数字仍按可用库存校验 |
| 售罄 | `SOLD_OUT` | 可用库存为零；商品继续展示，但该 SKU 不可下单 |
| 已停售 | `OFF_SALE` | 创作者停止该 SKU 新售；不得影响历史订单快照 |

创建商品订单时按 SKU 原子扣减“可用库存”并生成预占记录。待支付订单在取消、支付失败或 30 分钟超时关闭时释放预占；支付成功时预占转为正式占用。购物车只保存在 Cookie，不预占库存，结算时重新校验商品状态、SKU、价格、运费和库存。

## 8. 文旅活动自动校验、发布与报名状态机

活动必须绑定有效 IP 授权，但不要求先有二创作品。一个活动仅绑定一个原始 IP，必须填写实际举办地区，不能设置全国。

### 8.1 活动内容与运营状态

| 状态 | 枚举建议 | 含义 |
| --- | --- | --- |
| 提交中 | `SUBMITTING` | 创作者提交活动、场次、票种和规则 |
| 自动校验中 | `AUTO_CHECKING` | 校验授权、字段、场次票种和文本检测 |
| 已发布/报名中 | `PUBLISHED` | 消费者可浏览并预约 |
| 校验不通过 | `CHECK_REJECTED` | 禁止发布，退回创作者修改 |
| 校验异常 | `CHECK_ERROR` | 禁止发布，等待重新提交 |
| 暂停报名 | `BOOKING_PAUSED` | 已有人报名时停止后续预约，既有预约有效 |
| 已下架 | `DELISTED` | 仅无任何报名时可下架并重新创建 |
| 已结束 | `ENDED` | 全部场次已结束，停止新预约，进入未核销订单过期处理 |

| 当前状态 | 触发方 | 条件 | 目标状态 | 联动与限制 |
| --- | --- | --- | --- | --- |
| 无活动 | 创作者 | 有效授权、活动字段完整、固定退款模板已选 | `SUBMITTING` | 无草稿保存 |
| `SUBMITTING` | 系统 | 受理成功 | `AUTO_CHECKING` | 校验授权状态、期限、地区、场景、内容类型、票种/场次/名额和提交文字 |
| `AUTO_CHECKING` | 系统 | 校验通过 | `PUBLISHED` | 自动发布并生成发布凭证、存证；不经过人工内容审核 |
| `AUTO_CHECKING` | 系统 | 校验失败、疑似风险或文本检测不通过 | `CHECK_REJECTED` | 禁止发布，创作者修改后新提交 |
| `AUTO_CHECKING` | 系统 | 检测异常、超时或校验服务异常 | `CHECK_ERROR` | 禁止发布，创作者重新提交 |
| `PUBLISHED` | 创作者 | 无任何成功报名或有效预约 | `DELISTED` | 停止展示；需重新创建时新建活动 |
| `PUBLISHED` | 创作者 | 已有人报名，需要停止新增报名 | `BOOKING_PAUSED` | 已报名消费者由创作者线下联系；已生成订单继续按规则处理 |
| `BOOKING_PAUSED` | 创作者 | 需要恢复报名，授权与活动仍有效 | `PUBLISHED` | 恢复前重新校验当前授权有效性 |
| `PUBLISHED` / `BOOKING_PAUSED` | 系统定时任务 | 最后一个场次结束 | `ENDED` | 停止预约；未核销预约单进入过期处理 |

活动发布后，名称、地点、日期、场次、票种、价格、预约上限、取消/退款模板及其他规则均不可修改。发生变化时，尚无报名的活动可下架后重新创建；已有报名时只能暂停后续报名，不支持改期申请。

### 8.2 场次票种名额状态

每个“活动场次 + 票种”维护独立名额，不限制一期内场次数、票种数或活动累计预约人数。

| 名额动作 | 触发条件 | 结果 |
| --- | --- | --- |
| 锁定名额 | 消费者提交收费预约订单且名额充足 | 建立 30 分钟预占记录 |
| 正式占用 | 模拟支付成功，或免费预约确认成功 | 已用名额增加，生成电子核销码 |
| 释放名额 | 未支付超时、支付失败、用户取消或退款成功 | 释放预占或恢复已用名额 |
| 不恢复 | 已核销、活动结束未核销 | 保持已占用历史数据 |

## 9. 消费者订单、支付、物流与核销状态机

### 9.1 通用支付状态

| 支付状态 | 枚举建议 | 含义 |
| --- | --- | --- |
| 待支付 | `PENDING` | 已创建订单，等待模拟支付 |
| 支付成功 | `SUCCESS` | 适配器返回成功，保存支付流水号和时间 |
| 支付失败 | `FAILED` | 适配器返回失败，订单关闭 |
| 已关闭 | `CLOSED` | 用户取消或 30 分钟超时 |
| 已退款 | `REFUNDED` | 退款完成，保存模拟退款流水 |

支付成功回调必须幂等：同一支付流水只允许使同一订单成功一次。支付适配层一期为模拟实现，后续数字人民币仅替换适配接口，不改变订单状态机。

### 9.2 商品订单状态

| 状态 | 枚举建议 | 含义 |
| --- | --- | --- |
| 待支付 | `PENDING_PAYMENT` | 已锁库存，等待支付 |
| 已关闭 | `CLOSED` | 未支付取消、失败或超时，库存已释放 |
| 待发货 | `PENDING_SHIPMENT` | 已支付，等待平台履约客服发货（当前版本） |
| 已发货 | `SHIPPED` | 已录入真实物流并可查询轨迹 |
| 已签收 | `SIGNED` | 物流签收，进入消费者确认和售后保护期 |
| 售后中 | `AFTER_SALE` | 有进行中的售后，订单完成和分账冻结 |
| 已完成 | `COMPLETED` | 已确认收货或售后保护期结束，无进行中售后 |
| 已退款 | `REFUNDED` | 整单退款完成；部分退款以售后和退款明细体现，订单仍保留原履约状态 |

| 当前状态 | 触发方 | 条件 | 目标状态 | 联动 |
| --- | --- | --- | --- | --- |
| 无订单 | 消费者 | 已登录、商品已发布、SKU 可售、确认规则 | `PENDING_PAYMENT` | 锁定 SKU 库存；固化商品/SKU/价格/运费/地区/售后规则快照 |
| `PENDING_PAYMENT` | 消费者/系统 | 取消、失败或 30 分钟超时 | `CLOSED` | 释放库存 |
| `PENDING_PAYMENT` | 模拟支付适配器 | 支付成功 | `PENDING_SHIPMENT` | 支付成功；预占转正式占用 |
| `PENDING_SHIPMENT` | 履约客服 | 物流公司、运单号、可选发货时间/凭证/备注完整 | `SHIPPED` | 平台统一发货并记录物流轨迹；创作者自行发货为后续能力 |
| `SHIPPED` | 物流服务 | 返回签收 | `SIGNED` | 记录签收时间和凭证 |
| `SIGNED` | 消费者 | 确认收货且无售后中申请 | `COMPLETED` | 触发普通授权分账计算；独家买断不产生后续分账 |
| `SIGNED` | 系统定时任务 | 签收满 7 天且无售后中申请 | `COMPLETED` | 同上 |
| 可售后订单 | 消费者 | 提交符合模板的售后申请 | `AFTER_SALE` | 创建售后单；冻结未完成分账 |
| `AFTER_SALE` | 系统 | 售后被驳回/撤销且仍可履约 | 回到申请前状态 | 解除对应冻结 |
| `AFTER_SALE` | 系统 | 售后退款完成 | `REFUNDED` 或回到履约状态 | 按退款范围生成冲销；部分退款保留订单履约主状态 |

### 9.3 文旅预约订单与核销状态

| 状态 | 枚举建议 | 含义 |
| --- | --- | --- |
| 待支付 | `PENDING_PAYMENT` | 收费预约已锁定名额 |
| 已关闭 | `CLOSED` | 未支付、失败、取消或超时，名额释放 |
| 待核销 | `PENDING_VERIFICATION` | 已支付或免费预约成功，电子核销码有效 |
| 已核销 | `VERIFIED` | 履约客服现场核销成功，订单完成并触发分账 |
| 退款中 | `REFUNDING` | 已受理的取消/退款申请处理中 |
| 已退款 | `REFUNDED` | 退款成功，按规则恢复名额 |
| 已过期 | `EXPIRED` | 活动结束仍未核销，不退款、不触发分账 |

| 当前状态 | 触发方 | 条件 | 目标状态 | 联动 |
| --- | --- | --- | --- | --- |
| 无订单 | 消费者 | 已登录、活动报名中、票种名额可用、确认规则 | `PENDING_PAYMENT` | 收费票锁定名额；免费票可直接进入 `PENDING_VERIFICATION` |
| `PENDING_PAYMENT` | 消费者/系统 | 取消、失败或 30 分钟超时 | `CLOSED` | 释放名额 |
| `PENDING_PAYMENT` | 模拟支付适配器 | 支付成功 | `PENDING_VERIFICATION` | 正式占用名额，生成一次性核销码 |
| `PENDING_VERIFICATION` | 履约客服 | 核销码有效、活动/场次匹配且未使用 | `VERIFIED` | 核销码转已使用；订单完成；触发普通授权分账 |
| `PENDING_VERIFICATION` | 消费者 | 在固定模板允许的窗口内提交取消/退款 | `REFUNDING` | 创建活动退款售后单 |
| `REFUNDING` | 系统 | 退款完成 | `REFUNDED` | 恢复名额；生成分账冲销（如已产生相关冻结/明细） |
| `PENDING_VERIFICATION` | 系统定时任务 | 活动结束且未核销 | `EXPIRED` | 不退款，不触发活动完成分账 |

核销码子状态：`VALID`（可核销）→ `USED`（成功核销，不可再次使用）或 `EXPIRED`（活动结束未使用）。核销必须校验订单、活动、场次、票种和当前状态；重复核销须返回“已核销”，不得重复完成订单或重复分账。

## 10. 售后、退款与退货物流状态机

### 10.1 商品退货退款售后单

一期仅支持退货退款，不支持换货、补发和维修。已支付未发货可申请取消/退款；已发货只能申请退货退款。

| 状态 | 枚举建议 | 含义 |
| --- | --- | --- |
| 待审核 | `PENDING_REVIEW` | 消费者已提交申请，等待履约客服受理 |
| 已驳回 | `REJECTED` | 不符合固定售后模板或证据不足 |
| 退货中 | `RETURNING` | 需退货，消费者按指定地址寄回 |
| 待确认 | `PENDING_RECEIPT_CONFIRMATION` | 已上传退货物流，等待履约客服确认收货与退款条件 |
| 退款处理中 | `REFUND_PROCESSING` | 履约客服确认，等待财务复核和模拟退款 |
| 已完成 | `COMPLETED` | 退款与分账冲销均已完成 |
| 已撤销 | `WITHDRAWN` | 消费者在客服处理前撤回；恢复订单原状态 |

| 当前状态 | 触发方 | 条件 | 目标状态 | 联动 |
| --- | --- | --- | --- | --- |
| 无售后单 | 消费者 | 订单状态和售后模板允许，提交理由/凭证 | `PENDING_REVIEW` | 冻结未完成分账；锁定订单、SKU、规则和退货地址快照 |
| `PENDING_REVIEW` | 消费者 | 客服尚未处理 | `WITHDRAWN` | 解冻可解冻的分账，订单回原状态 |
| `PENDING_REVIEW` | 履约客服 | 不符合模板或证据不足 | `REJECTED` | 解冻可解冻的分账，订单回原状态 |
| `PENDING_REVIEW` | 履约客服 | 已支付未发货取消退款成立 | `REFUND_PROCESSING` | 无需退货 |
| `PENDING_REVIEW` | 履约客服 | 已发货退货退款成立 | `RETURNING` | 使用按履约方式锁定的退货地址 |
| `RETURNING` | 消费者 | 上传退货物流单号 | `PENDING_RECEIPT_CONFIRMATION` | 记录退货物流 |
| `PENDING_RECEIPT_CONFIRMATION` | 履约客服 | 确认收货与退款条件 | `REFUND_PROCESSING` | 写入验收结论 |
| `REFUND_PROCESSING` | 财务 | 退款金额复核通过，模拟退款成功 | `COMPLETED` | 生成退款单、退款流水和比例冲销记录 |

退货地址一经售后单创建即锁定：创作者自行发货使用该创作者退货地址，平台统一发货使用平台退货地址。特殊争议仅平台管理员处理，不改变履约客服审核、收货确认和财务金额复核的主职责。

### 10.2 活动取消/退款售后单

活动不支持改期。已核销和活动结束未核销的预约不允许取消或退款。

| 状态 | 流转 |
| --- | --- |
| `PENDING_REVIEW` | 消费者在模板允许窗口内提交取消/退款申请，履约客服待受理 |
| `REJECTED` | 履约客服驳回，不改变预约有效性 |
| `REFUND_PROCESSING` | 履约客服受理后，财务复核退款金额 |
| `COMPLETED` | 模拟退款成功，预约订单转 `REFUNDED` 并恢复名额 |
| `WITHDRAWN` | 消费者在客服处理前撤回，预约订单回 `PENDING_VERIFICATION` |

活动取消/退款的金额、时间窗口和可退比例必须以活动发布时选定的固定模板快照判定，不得读取后来修改的模板。

### 10.3 退款单状态

| 状态 | 枚举建议 | 含义 |
| --- | --- | --- |
| 待财务复核 | `PENDING_FINANCE_REVIEW` | 履约客服已确认可退款 |
| 退款处理中 | `PROCESSING` | 已提交模拟退款适配器 |
| 已退款 | `REFUNDED` | 模拟退款成功，保存退款流水 |
| 退款失败 | `FAILED` | 适配器失败，保留重试与人工处理记录 |
| 已驳回 | `REJECTED` | 财务复核不通过，退回履约客服处理 |

退款成功是售后单 `COMPLETED` 的必要条件。退款失败不得将售后标记完成；应保留在处理中或失败待处理状态，并冻结对应分账。

## 11. 自动分账、冲销与结算状态机

### 11.1 普通授权分账记录

普通授权的商品订单完成、活动订单核销后，系统按订单快照自动计算原始 IP 权益方、创作者、城市运营和平台服务费。运费不进入分账基数；金额四舍五入差额归平台服务费。

| 状态 | 枚举建议 | 含义 |
| --- | --- | --- |
| 待计算 | `PENDING_CALCULATION` | 订单已达到触发条件 |
| 已计算 | `CALCULATED` | 已生成各方金额与比例快照 |
| 已冻结 | `FROZEN` | 售后、退款、风险处置或争议期间不得结算 |
| 已冲销 | `REVERSED` | 退款对应金额已按规则冲销 |
| 待结算 | `PENDING_SETTLEMENT` | 财务复核可进入结算批次 |
| 已结算 | `SETTLED` | 线下付款完成且凭证已上传 |

| 当前状态 | 触发方 | 条件 | 目标状态 | 联动 |
| --- | --- | --- | --- | --- |
| 无记录 | 系统 | 商品订单 `COMPLETED` 或活动订单 `VERIFIED` | `PENDING_CALCULATION` | 仅普通授权生成；独家买断的后续商品/活动不生成分账 |
| `PENDING_CALCULATION` | 系统 | 分账规则、金额和关联主体完整 | `CALCULATED` | 保存金额、比例、规则与订单快照 |
| `CALCULATED` | 系统 | 无售后、退款、风险或争议 | `PENDING_SETTLEMENT` | 可供财务复核和入批 |
| `CALCULATED` / `PENDING_SETTLEMENT` | 系统 | 售后、退款、风险处置或争议发生 | `FROZEN` | 阻止结算 |
| `FROZEN` | 系统/财务 | 售后被驳回、撤销或争议解决且无需退款 | `PENDING_SETTLEMENT` | 解冻并保留原因 |
| `CALCULATED` / `FROZEN` / `PENDING_SETTLEMENT` | 系统 | 退款成功 | `REVERSED` | 按实际退款金额同比例冲销；部分退款只冲销对应商品/SKU/票种金额 |
| `PENDING_SETTLEMENT` | 财务 | 复核通过并纳入结算批次 | 保持 `PENDING_SETTLEMENT` | 以结算批次状态驱动付款，记录复核结论 |
| `PENDING_SETTLEMENT` | 财务 | 对应结算批次付款成功且凭证完整 | `SETTLED` | 写入付款日期、凭证和实际金额 |

### 11.2 独家买断费用分配

独家买断的“授权购买费用”单独生成买断费用分配记录，参与方为原始 IP 权益方、城市运营和平台；创作者是付款方，不参与该笔费用分配。该记录可使用与普通分账相同的 `PENDING_CALCULATION`、`CALCULATED`、`FROZEN`、`PENDING_SETTLEMENT`、`SETTLED` 状态，但必须标记 `distribution_type = BUYOUT_FEE`。

独家买断后，创作者创建的商品、活动订单标记 `distribution_type = CREATOR_OWNED`：只记录订单收入，不创建原始 IP 权益方、城市运营或平台的后续二传分账，也不计平台服务费。

### 11.3 结算批次状态

| 状态 | 枚举建议 | 含义 |
| --- | --- | --- |
| 草稿 | `DRAFT` | 财务选择待结算明细中 |
| 待复核 | `PENDING_REVIEW` | 批次金额、收款主体和明细待确认 |
| 待付款 | `PENDING_PAYMENT` | 复核完成，等待线下付款 |
| 付款处理中 | `PAYING` | 财务执行线下付款 |
| 已完成 | `COMPLETED` | 所有明细已付款并上传凭证 |
| 部分完成 | `PARTIALLY_COMPLETED` | 部分明细付款成功，失败明细留待处理 |
| 已作废 | `VOIDED` | 未付款前取消批次，明细回待结算 |

结算批次只可包含状态为 `PENDING_SETTLEMENT` 且未被冻结、未冲销、未结算的记录。实际付款为线下操作，系统须上传付款凭证并记录付款状态，不得将“生成批次”视为已付款。

## 12. 真实存证状态机

一期要求真实存证，但链服务提供方可替换。任何对象均不得因“已提交上链”而虚报为上链成功。

| 状态 | 枚举建议 | 含义 |
| --- | --- | --- |
| 待生成摘要 | `PENDING_HASH` | 文件或业务快照已创建，等待 Hash |
| 待上链 | `PENDING_CHAIN` | Hash 完成，等待链适配器提交 |
| 上链中 | `CHAINING` | 已向链服务提交 |
| 上链成功 | `SUCCESS` | 已取得可验证存证编号/交易或回执编号 |
| 上链失败 | `FAILED` | 提交或确认失败，保留失败原因与重试记录 |

| 当前状态 | 触发方 | 条件 | 目标状态 | 说明 |
| --- | --- | --- | --- | --- |
| 无记录 | 系统 | 形成需要存证的文件或业务快照 | `PENDING_HASH` | 覆盖 IP、合同、作品、发布、订单、物流、核销、售后、退款、买断分配等关键对象 |
| `PENDING_HASH` | 系统 | Hash 生成成功 | `PENDING_CHAIN` | 保存 Hash 与文件/快照版本 |
| `PENDING_CHAIN` | 链适配器 | 发起提交 | `CHAINING` | 保存请求编号 |
| `CHAINING` | 链适配器 | 获得成功回执 | `SUCCESS` | 保存链平台、存证编号、交易/回执编号、时间 |
| `CHAINING` | 链适配器 | 失败、超时或回执不确定 | `FAILED` | 保存失败类别；按重试策略再次进入 `PENDING_CHAIN` |

IP 上架、授权合同生效、作品确权等依赖存证的关键节点，须明确校验需要“已上链成功”还是可进入“待补偿上链”。一期基线中 IP 上架前的关键材料和作品确权要求真实存证完成，因此这些节点必须为 `SUCCESS` 才可完成主状态流转。订单、物流等后置凭证可以先完成业务，再持续重试存证，但后台必须展示失败状态。

## 13. 跨对象流转与禁止规则

### 13.1 关键联动表

| 触发对象/事件 | 必须联动的对象 |
| --- | --- |
| IP 确权成功 | 固化权利人、主城市、授权方案、分配规则与商城展示快照；发起关键材料存证 |
| IP 上架 | 校验方案 `ENABLED`、资料完整、关键材料存证 `SUCCESS`；开放创作者商城可见性 |
| 授权订单支付成功 | 生成授权记录、合同、凭证、范围快照、下载权限与存证；占用名额；买断时隐藏 IP |
| 授权到期/解除 | 关闭素材下载、新作品/商品/活动创建、新销售/预约；保留历史；处理未完成履约与冻结资金 |
| 作品确权成功 | 开放该作品关联商品；发起作品确权存证 |
| 商品/活动自动发布 | 生成发布凭证与存证；开放 H5 可见性和下单/预约能力 |
| 商品订单支付成功 | 库存预占转正式占用；进入待发货 |
| 活动预约支付/免费确认 | 名额正式占用；生成一次性电子核销码 |
| 商品签收确认/自动完成 | 普通授权生成分账；独家买断不生成后续分账 |
| 活动核销成功 | 预约订单完成；普通授权生成分账；核销码永久失效 |
| 售后/退款申请 | 冻结未完成分账；锁定售后和退货地址快照 |
| 退款成功 | 更新订单/预约状态；释放库存或名额（适用时）；生成退款流水、分账冲销与关键凭证存证 |
| 结算批次付款完成 | 分账明细标记已结算；保存线下付款凭证 |

### 13.2 重要禁止规则

1. 未实名或认证中的创作者不得购买 IP 授权、下载素材、提交作品、创建商品或活动。
2. 已停用账号不得产生任何新增业务操作；不得删除其既有合同、订单、存证或结算记录。
3. 未上架、暂停、下架、失效或售罄 IP 不得创建新的授权订单。
4. 同一创作者在同一时间只能持有一笔同一 IP 的有效授权；并发请求必须使用唯一约束和名额原子扣减防止重复购买。授权到期后，可以按届时有效的新方案重新购买并生成新的授权记录。
5. 授权订单支付成功即合同生效，不允许普通取消或退款。
6. 授权过期或解除后不得下载新素材、创建新内容、继续新增销售或预约。
7. 商品必须关联已确权作品；活动不强制关联作品，但必须有有效 IP 授权。
8. 商品和活动不得进入人工发布审核队列；自动校验不通过、疑似风险或异常均禁止发布。
9. 活动发布后不得修改名称、地点、日期、场次、票种、价格、名额和取消/退款规则；有报名的活动不得下架。
10. 购物车不锁库存；支付超时必须释放商品库存、活动名额或授权名额。
11. 已核销活动预约不得取消、退款或再次核销；活动结束未核销不得退款，也不得产生完成分账。
12. 商品只支持退货退款；活动只支持取消退款；两者都不支持改期，商品也不支持换货、补发或维修。
13. 售后、退款、风险处置、争议期间对应分账不得结算。
14. 独家买断的后续商品/活动收入不得生成普通分账和平台后续服务费。
15. 任何“上链成功”状态都必须有可验证的回执或存证编号；仅提交请求不得标记成功。

## 14. 超时任务、并发与异常处理

| 场景 | 系统任务/接口行为 | 幂等与审计要求 |
| --- | --- | --- |
| 待支付超时 | 创建后 30 分钟自动关闭授权、商品、活动收费订单，释放相应名额或库存 | 使用订单状态 + 版本号条件更新；重复执行不得重复释放 |
| 支付回调重复 | 同支付流水多次回调 | 只接受第一次有效成功；后续记录为重复回调，不重复占用或生成合同 |
| 库存/名额并发 | 多用户同时下单/预约/购买授权 | 在数据库事务内原子预占；不足时返回失败，不创建成功待支付订单 |
| 敏感内容检测超时 | 外部接口不可用或结果不确定 | 主流程进入 `CHECK_ERROR` / `TEXT_CHECK_ERROR`，禁止发布或审核流转，可重新提交 |
| 链上回执超时 | 上链请求无最终回执 | 状态保留 `FAILED` 或 `CHAINING` 的可追溯记录，按策略重试；不得伪造成功 |
| 物流回调重复/乱序 | 同一运单多次或乱序推送 | 按物流事件时间和状态优先级处理；签收后不得回退为运输中 |
| 核销重复 | 已使用核销码再次扫描 | 返回已核销，禁止重复完成订单、恢复名额或重复分账 |
| 退款重复 | 同售后单重复提交退款 | 退款单唯一约束；只允许一个有效退款处理任务 |
| 授权到期 | 定时扫描授权结束时间 | 仅由 `ACTIVE` 转 `EXPIRED` 一次，并写入受影响商品/活动停止新增操作记录 |

## 15. 接口与测试验收最小要求

### 15.1 接口返回要求

所有涉及状态变更的接口至少返回：业务对象编号、变更前状态、变更后状态、处理结果、失败原因编码、下一步可执行动作和最新版本号。前端不得自行推断状态成功，应以接口返回的状态为准。

### 15.2 必测状态路径

1. IP：录入 → 审核退回 → 补充 → 确权并自动上架；以及暂停、下架、到期。
2. 授权方案：草稿 → 合规确认 → 启用 → 被 IP 绑定后禁止修改/停用。
3. 授权购买：待支付超时释放名额；支付成功后合同和授权生效；买断后 IP 隐藏；到期/解除后限制新操作。
4. 作品：文本通过/疑似/不通过/异常，以及版权初审、合规复核、退回重提、确权成功。
5. 商品：有效授权+已确权作品自动发布；授权越界、文本疑似、接口异常均禁止发布；售罄仍展示但不能下单。
6. 活动：自动发布；免费和收费预约占用名额；有报名后只能暂停报名；结束未核销转过期。
7. 商品订单：30 分钟关闭、支付、发货、签收、确认收货/自动完成、售后冻结、退款冲销。
8. 活动订单：支付或免费确认、核销一次性、取消退款、活动结束未核销不退款。
9. 分账结算：普通授权自动计算、退款比例冲销、独家买断不生成后续分账、线下付款凭证后完成。
10. 存证：成功回执、失败重试、不得将待上链或失败显示为成功。

## 16. 已确定、待配置具体值的项目

下列为一期已确定“需要配置”、但尚未指定具体数值或供应商的信息，不改变本状态机：

- 第三方实名、短信、敏感内容检测、物流、文件存储和链上存证服务的接入参数；
- 图形验证码、短信验证码的有效期、发送频率和错误次数阈值；
- 商品签收后的售后保护期；
- 固定取消/退款模板对应的申请窗口、可退款比例和特殊条件；
- 存证重试次数、重试间隔、失败告警阈值；
- 平台退货地址、平台服务热线和创作者退货地址的维护规则。

这些参数需要在后续“系统配置清单”“数据库字段字典”和“接口错误码”文档中具体化，但不需要改变已确认的业务状态和流转方向。
