# 星衍树前端 AI 启动指令

## 1. 你拿到的材料

本目录是需求与接口契约包，不是 Vue 项目源码。请在另行提供的实际 Vue 前端仓库中开发，禁止修改本目录中的需求基线、OpenAPI 和原型文件。

先阅读：

1. `README.md`
2. `前端AI变更摘要.md` 的最新一条
3. `01-需求与业务规则/一期MVP需求基线与范围说明.md`
4. 当前任务页面对应的字段清单、状态机、OpenAPI、字段绑定和测试用例

## 2. 当前允许开发的页面

仅实现已有接口支撑的统一管理后台页面：

- 后台登录与当前用户信息；
- 后台账号管理、组织管理；
- 平台参数、地区管理、标签管理、固定售后模板；
- 文件上传、文件详情、受控下载；
- IP 列表、IP 新建/编辑/补充材料；
- 授权方案、分账结构模板；
- 待审核 IP 队列、DCI 代办、DCI 核验、权属与授权边界确认。

不要开发消费者 H5、创作者、商品、活动、订单、履约、财务、看板、角色权限配置、检测记录、存证/审计列表等未具备完整接口的页面，也不要在菜单中展示它们。

## 3. 开发与联调输入

开始前必须从项目负责人取得以下信息：

| 项目 | 必需内容 |
| --- | --- |
| 前端源码 | Vue 项目仓库或空项目目录、包管理器、Node.js 版本、现有组件库与视觉规范 |
| 后端地址 | 测试环境 API Base URL；本机默认可使用 `http://127.0.0.1:8080/api/v1`，以实际启动地址为准 |
| 联调账号 | 平台管理员、城市运营、版权/合规三类测试账号及其所属组织；不得把生产账号或真实密钥写入代码 |
| 跨域 | 测试环境前端 Origin；后端测试环境已可配置跨域，生产环境必须配置具体域名，不使用 `*` |
| 文件策略 | 当前允许上传的文件类型和大小限制；前端只做体验性预校验，最终以 `POST /files` 结果为准 |

不得要求或保存 MySQL、Redis、COS、短信、内容检测、支付或电子签章的真实密钥。这些都只由后端配置和调用。

## 4. 固定前端实现规则

- 业务 ID、订单号、文件 ID 均按字符串处理，禁止转为 JavaScript `Number`。
- 登录使用 `POST /auth/login`：所有账号先调用 `GET /auth/captcha`，提交账号、密码和图形验证码，不传 `loginType`；菜单、按钮权限和数据范围以 `GET /auth/me` 为准。
- 写接口按 OpenAPI 带 `Authorization`；适用时还必须带 `If-Match-Version` 与 `Idempotency-Key`。
- 先用 `POST /files` 上传，业务请求只传 `fileId`；下载通过 `POST /files/{fileId}/download-url` 获取短期 URL。
- 前端不直连腾讯文本检测、COS 或存证服务；文本检测与存证由业务接口后端处理。
- 每页必须处理加载、空态、无权限、字段校验、接口失败、提交中、版本冲突和幂等重放提示。
- 严格遵循最新管理后台原型；B02 必须是完整八段式表单，不能退化为通用字段弹窗。

## 5. 每次任务的输出

每次只领取一个页面或紧密相关的一组页面。完成后提交：

1. 修改文件清单；
2. 已绑定的接口、请求字段、响应字段和请求头；
3. 已完成的交互与状态处理；
4. 自测方式、结果和截图；
5. 尚需后端或产品确认的问题。

首次任务建议从“登录、请求封装、鉴权、`GET /auth/me` 菜单与路由守卫”开始；完成后再做平台管理员的账号、组织和基础配置。
