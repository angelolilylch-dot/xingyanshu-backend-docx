# 星衍树一期 MVP 已实现菜单与接口对照表

版本：v0.4  
用途：前端开发与联调只以本表列出的菜单和接口为当前可用范围；未列出的商城、订单、商品、活动、履约、售后、结算与看板接口仍待后端开发。

## 1. 通用约定

- API 前缀：`/api/v1`。
- 后台接口使用后台登录获得的 `Authorization: Bearer {accessToken}`；创作者接口使用创作者注册后返回的创作者 Token，二者不可混用。
- 所有业务 ID 均按字符串处理；编辑、启停和审核接口需要 `If-Match-Version` 请求头。
- 创建 IP、提交 IP、代办申请、审核等接口还需要 `Idempotency-Key`；创作者注册和实名当前不要求该请求头。
- 文件先上传再引用：后台上传 `POST /files`；创作者委托书上传 `POST /creator/files`；成功后使用 `data.id` 作为 `fileId`。

## 2. 当前原型信息架构

菜单只代表业务域；列表、详情、表单、审核和状态操作均在该业务域内完成，不为单一动作再增加侧栏菜单。

| 角色 | 侧栏业务域 | 页面内组织 | 当前可用接口 |
| --- | --- | --- | --- |
| 未登录 | 统一后台登录 / 创作者注册 | 登录页不选择角色；账号、密码和图形验证码由服务端识别账号类型。消费者仅使用 H5，不进入本页。 | `GET /auth/captcha`、`POST /auth/login`、`POST /auth/refresh`、`POST /auth/logout`、`GET /auth/me`、`POST /creator/auth/sms/send`、`POST /creator/auth/register` |
| 平台管理员 | 账号与组织 | 页签：账号管理、组织管理 | 账号与组织相关 `admin/accounts`、`admin/orgs` 接口 |
| 平台管理员 | 平台配置 | 页签：平台参数、地区管理、标签管理、固定售后模板 | `admin/configs`、`admin/regions`、`admin/tags`、`admin/after-sale-templates` 接口 |
| 平台管理员 | IP 管理 | 列表、详情和自动上架结果查看；上架记录只在详情展示 | `GET /ips`、`GET /ips/{ipId}` |
| 平台管理员 | 授权方案管理 | 页签：授权方案、分账结构模板；列表、详情、草稿、审核、启停均在页签内完成 | `auth-plans`、`distribution-templates` 接口 |
| 城市运营 | 城市 IP 管理 | 列表、新建、草稿编辑、补充材料、评估报告、DCI 代办、提交合规、进度查看 | `ips`、评估报告、DCI 代办、提交、文件、方案和字典接口 |
| 版权/合规 | IP 合规审核 | 页签：待审核 IP、审核详情、DCI 代办；详情由选中待审核 IP 后在当前业务域打开 | 合规待审、DCI 代办、DCI 核验、权属审核、评估报告接口 |

文件上传、文件信息和受控下载是表单内通用能力，当前不设置独立主菜单。商城、订单、商品、活动、履约、售后、结算和看板仍不在本轮原型侧栏中展示。

| 菜单/页面 | 当前可用接口 | 说明 |
| --- | --- | --- |
| B01 平台 IP 管理 | `GET /ips`、`GET /ips/{ipId}` | 仅平台管理员。确权成功且存证完成后由系统自动进入 `LISTED`，平台管理员只查看结果。 |
| B02 城市 IP 管理 | `GET /ips`、`POST /ips`、`GET/PATCH /ips/{ipId}`、`POST /ips/{ipId}/submit`、`POST /ips/{ipId}/evaluation-reports`、`POST /ips/{ipId}/dci-assistance-requests` | 仅城市运营；所有入库、补充与进度动作均在同一菜单内完成。 |
| B03 IP 合规审核 | `GET /compliance/ips/pending`、`GET /ips/{ipId}`、`GET /compliance/dci-assistance-requests`、`POST /compliance/dci-assistance-requests/{requestId}/handle`、`POST /compliance/dci-assistance-requests/{requestId}/application-package`、`POST /ips/{ipId}/dci-verifications`、`POST /ips/{ipId}/rights-reviews`、`POST /ips/{ipId}/evaluation-reports` | 仅版权/合规；“待审核 IP / 审核详情 / DCI 代办”三个页签，代办项可生成并下载私有 ZIP 资料包。 |
| B04 授权方案管理 | `GET/POST /auth-plans`、`GET/PATCH /auth-plans/{planId}`、`POST /auth-plans/{planId}/submit|reviews|enable|disable`、`GET/POST /distribution-templates`、`GET/PATCH /distribution-templates/{templateId}`、`PATCH /distribution-templates/{templateId}/status` | 仅平台管理员；“授权方案 / 分账结构模板”两个页签。分账模板只定义参与方，不定义比例。 |
| 公共下拉数据 | `GET /dictionaries/{dictType}`、`GET /public/regions`、`GET /tags` | 用于下拉、单选、复选数据加载。 |

## 5. 创作者注册与实名入口

创作者登录或刷新后必须调用 `GET /auth/me`，仅按返回菜单渲染：`MENU_CREATOR_WORKSPACE`（C01 工作台）、`MENU_CREATOR_ONBOARDING`（C01 注册/实名认证）、`MENU_CREATOR_IP_MALL`（C02 IP 商城）。C03 及后续菜单在接口未返回前不得显示。

| 菜单/页面 | 当前可用接口 | 说明 |
| --- | --- | --- |
| C01 创作者注册 | `POST /creator/auth/sms/send`、`POST /creator/auth/register` | 测试环境短信 Mock 固定验证码为 `123456`，并在响应中返回 `data.mockCode`；注册请求字段为 `mobile`、`password`、`smsCode`、`displayName`。 |
| C01 创作者实名认证 | `POST /creator/identity-verifications`、`GET /creator/identity-verifications/latest` | 字段为 `subjectType`、`legalName`、`credentialType`、`credentialNo`；个人、企业、工作室均使用 Mock 自动核验。 |
| C01 授权委托书 | `GET /creator/authorization-letter-template`、`POST /creator/files`、`POST /creator/authorization-letters` | 仅企业/工作室可上传。委托书状态为 `FILED`，只作资料留存，不需要管理员确认，也不影响购买资格。 |
| 创作者账号状态 | `PATCH /admin/creators/{creatorId}/status` | 平台管理员启用或停用创作者；停用后创作者会话失效。 |
| C02 创作者 IP 商城 | `GET /creator/ip-mall`、`GET /creator/ip-mall/{ipId}`、`GET /creator/ip-mall/{ipId}/purchase-preview` | 仅展示已上架、商城可见且授权方案启用的 IP；预览返回实名、重复授权、名额售罄等购买限制。 |
| IP 商城上架 | 无独立接口 | `rights-reviews` 确权成功并取得存证回执后，系统将 IP 自动置为 `LISTED` 并设置 `mallVisible=true`。 |
