# 消费者 H5 联调与验收说明

## 当前真实接口验收

- 游客可以访问首页、商品/活动列表和详情、客服、地区、公开图片；响应中不得出现 `ipId`、IP 名称、创作者、品牌或内部资料。
- 暂停报名活动仍在活动列表/详情中可见，前端显示“报名暂停”并禁用预约。
- 商品售罄时仍显示卡片和详情，但隐藏/禁用购买动作。
- 测试环境短信 Mock 发码后，同一手机号在 60 秒内不可重发；生产页面不显示或保存 `mockCode`。
- 短信登录必须先勾选协议；首次和后续成功登录均留存协议版本/时间；登录成功后可读取 `/consumer/me`；消费者 Token 访问 `/auth/me` 必须被拒绝。
- 两个设备可同时保持同一手机号的消费者会话；刷新 Token 后旧 refreshToken 失效；退出后仅当前设备的受保护消费者接口返回未登录。

## H5-02 接入后的补充验收

已实现并以真实 MySQL 8 HTTP 用例验收：地址簿、商品订单预览/创建/查询/取消、30 分钟库存预占与超时释放、测试环境 Mock 支付成功/失败，以及平台发货、物流轮询落库、签收、消费者物流查询、确认收货和签收 7 天自动确认。生产环境不注册 Mock 支付路由；包裹拆分、物流回调入口和售后仍分别等待后续能力/API-AFS-01。

- 本地购物车不产生服务端库存锁定。
- 多创作者、多商品、多 SKU 可合为一笔平台订单；任一 SKU 不可售时整笔创建失败，不生成部分订单。
- 地址簿上限 10 条；历史订单保留完整收货地址快照。
- 同一幂等键不会重复创建订单或重复预占；待支付 30 分钟超时释放库存。
- Mock 支付成功、失败均可测试；生产环境拒绝 Mock 支付。

## H5-03 接入后的补充验收

已于 2026-10-09 以真实 MySQL 8 HTTP 用例验收：免费票预约/核销码、收费票预占、Mock 支付失败与成功、创建幂等、场次名额不足、支付超时释放、活动结束过期、消费者 JWT 越权拒绝。

- Mock 支付仅 test 环境存在；生产环境该路由返回 404。真实微信 H5 支付仍是 API-FND-05-R1 的后续工作。
- API-FUL-02 尚未实现现场核销，前端不得将“待核销”显示为已参加或已完成。
- 默认订单只生成一个包裹；仅超重/超体积时可拆包，仍属于同一订单。
