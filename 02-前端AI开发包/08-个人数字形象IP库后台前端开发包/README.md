# 个人数字形象 IP 库后台前端开发包

本包面向管理后台前端 AI，与 `07-个人数字形象IP库独立H5开发包` 完全分离。后台采用既有管理员登录态；禁止以 `AVATAR_H5` token 调用，禁止展示或下载用户原始素材、完整身份证号、身份证哈希、归档包密码或永久对象地址。

阅读顺序：

1. `01-前端AI启动指令.md`
2. `Avatar_Admin_OpenAPI_v1.yaml`：后台接口路径、鉴权、请求体及统一响应封装。
3. `02-页面业务逻辑与接口清单.md`
4. `03-后台Mock联调与验收.md`
5. `M:\工作目录\星恒云创\02-原型\管理后台\个人数字形象管理模块原型.html`
6. `个人数字形象名单导入模板.xlsx`：目标四列模板（姓名、身份证号、性别、手机号码），**待后端升级后启用，不能上传至当前接口**。
7. `M:\工作目录\星恒云创\01-交付文档\v0.5\01-主设计文档\个人数字形象IP库_数据库与API详细设计.md`
8. `G:\Go\xingyanshu-backend\internal\modules\avatar\avatar.go`（真实路由）

当前可开发页面：城市名单、名单导入批次与错误回执、城市建档入口及二维码、提醒短信、城市档案进度、进度导出、平台人工质检、删除审批和归档包导出。

重要边界：名单导入使用“姓名、身份证号、性别、手机号”四列模板，前端须通过 `GET /avatar/rosters/template` 下载后再上传。身份证号仅用于服务端加密入库；点击“立即执行实名核验”后，后端调用腾讯云 `PhoneVerification` 三要素核验。页面不得展示、缓存、记录日志或导出身份证号、腾讯云请求参数、响应明细或密钥。采集提交后的人脸一致性核验不是后台页面触发的操作；由后端 worker 自动执行，后台只可在档案进度中查看脱敏后的状态，不能展示实名明文、相似度或第三方原始响应。
