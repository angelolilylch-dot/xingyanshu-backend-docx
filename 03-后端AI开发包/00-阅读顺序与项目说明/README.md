# 星衍树版权二创平台一期 MVP 后端 AI 开发包

本目录供完全不了解项目的后端 AI 使用。所有文件为 `功能结构图\v0.4` 的副本；开发任务应在实际后端代码仓库中完成，**不要修改本开发包中的需求基线**。

## 1. 项目背景与目标

### 1.1 建设背景

星衍树面向城市文化资源、非遗、历史人物、地方技艺等 IP 的版权共创与运营。平台把原本分散的权属材料、授权协商、二创内容、文创销售、文旅活动、履约结算与证据材料，收拢为可追溯的线上业务闭环。

平台的核心问题不是单纯做一个电商商城，而是让每一件商品、每一个活动都能追溯到：来源 IP、原始权利人、固定授权方案、创作者有效授权、作品确权结果、订单履约记录和相应的分账/存证凭证。

### 1.2 一期目标

一期 MVP 要证明以下闭环能够真实运行：

```text
城市运营录入 IP
→ 版权/合规确权并确认授权/分配方案
→ 平台管理员上架 IP
→ 创作者完成实名并购买 IP 授权
→ 支付后生成授权合同、凭证和范围快照
→ 创作者提交作品，版权/合规审核并确权
→ 创作者基于授权创建商品或文旅活动
→ 系统自动校验授权边界和敏感内容后发布
→ 消费者在 H5 浏览、购买商品或预约活动
→ 发货签收或现场核销
→ 售后退款（适用时）、自动分账、线下结算和关键凭证真实存证
```

### 1.3 两端与角色边界

一期有两个前端端：

- **统一管理后台：** 平台管理员、集团管理层、城市运营、版权/合规、创作者、财务和履约客服共用一套后台，通过 RBAC 和数据范围隔离权限。
- **消费者 H5：** 游客仅可浏览公开商品和活动；不提供公开 IP 信息。消费者登录后可购买、预约、查看物流/核销码和申请售后。

其中，城市运营只负责本城市 IP 信息录入和初步方案选择，不能创作或审核商品/活动；版权/合规负责 IP、作品及商品的版权初审/合规复核；平台管理员负责 IP 上架、平台规则和风险处置；商品经自动校验和二级审核后发布，活动通过服务端自动校验后发布。

### 1.4 一期技术与外部边界

后端采用 Go，数据库采用 MySQL。支付一期只实现模拟支付，为未来数字人民币预留替换接口；短信、物流、文件存储可对接。关键业务凭证需要真实存证上链，但链服务商的具体配置属于环境项，不能伪造成功回执。

## 2. 必读顺序与权威优先级

发生冲突时，严格按以下优先级处理：

1. `01-需求与业务规则/一期MVP需求基线与范围说明.md`：一期范围与业务结论的最高依据；
2. `01-需求与业务规则/业务流程与关键规则.md`：业务角色、流程顺序、前置条件、快照、权限和异常边界；
3. `01-需求与业务规则/业务状态机与流转规则.md`：状态、超时、并发、禁止规则和跨对象联动；
4. `00-阅读顺序与项目说明/后端技术架构与工程规范.md`：已确认的 Gin、GORM、内置 SQL 迁移、Redis、鉴权、任务与工程组织方式；
5. `03-接口契约/OpenAPI_v0.4.yaml`：前后端请求、响应、错误码、鉴权和幂等契约；
5. `02-数据库设计/数据库设计说明.md`、字段字典与 SQL：数据库对象、字段和落库约束；
6. `04-开发执行与测试/API功能清单与开发任务拆分.md`：任务范围、涉及表和验收；
7. `04-开发执行与测试/测试验收标准与测试用例.md`：实现后的验收依据；
8. `05-前端参考/*`：理解页面动作和用户可见字段，不得以原型覆盖前述业务规则。

## 3. 每次领取任务的操作顺序

1. 在 `04-开发执行与测试/AI任务下发执行计划.md` 中确认当前可下发的任务及其前置依赖；
2. 复制 `04-开发执行与测试/AI单任务开发模板.md` 的“后端接口开发模板”，填入任务编号；
3. 阅读该任务关联的 API、状态机、数据表和测试用例；
4. 在真实代码仓库中实现最小范围的路由、DTO、服务、事务、仓储、迁移和测试；
5. 同步 OpenAPI 或确认实现严格符合现有 OpenAPI；
6. 在 `03-接口契约/接口开发记录.md` 追加请求地址、测试请求/响应 JSON、涉及表和测试结果；
7. 按模板输出实现摘要、变更文件、测试结果、requestId 示例及阻塞项。

## 4. 后端强制约束

- MySQL **不建立物理外键**；逻辑关联、数据范围和状态校验在 Go 服务事务中实现。
- 业务 ID 使用字符串；金额使用十进制字符串或高精度金额类型，绝不使用浮点数计算金额。
- 所有写接口都必须实现：鉴权、角色/数据范围、字段校验、状态机前置、乐观锁、幂等、状态历史和审计日志。
- 所有用户提交文字按规则调用第三方敏感内容检测。商品检测/授权边界校验通过后进入版权初审、合规复核；活动检测/授权边界校验通过后自动发布，不得实现活动人工发布审核。
- 授权支付成功后合同与授权生效，不支持取消或退款；待支付订单 30 分钟关闭并释放预占。
- 文件只返回 `fileId` 和短期签名下载地址；私有文件、合同、版权证明、实名信息和分账细项必须按权限脱敏。
- 外部回调使用 HMAC、请求号、时间窗口和幂等保护；回调失败、超时、重复或乱序不得破坏业务终态。
- 存证只有拿到真实服务商回执后才能为成功；失败必须可追踪和重试。

## 5. 一期明确不做

真实支付或数字人民币、自动续期、授权成功后的取消退款、发票、活动改期、提货自取、商品草稿、多账号、优惠券/会员/复杂营销、投诉工单、活动人工发布审核。
