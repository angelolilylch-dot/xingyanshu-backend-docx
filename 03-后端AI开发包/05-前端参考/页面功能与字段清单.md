## 1. 使用约定

### 1.1 文档优先级

字段业务含义、控件和枚举以《页面功能与字段清单》为准；接口路径、请求/响应字段、错误码和鉴权以 `OpenAPI_v0.4.yaml` 为准；状态与可执行动作用《业务状态机与流转规则》约束。冲突时，按此顺序处理：MVP 基线 → 状态机 → OpenAPI → 本清单 → 原型。

### 1.2 绑定记法

| 记法 | 含义 |
| --- | --- |
| `UI ← data.xxx` | 页面展示/回填接口响应字段 |
| `UI → request.xxx` | 页面提交时映射到请求字段 |
| `字典：DICT_XXX` | 下拉/单选/复选数据由字典接口加载，禁止写死中文值 |
| `动作：availableActions` | 按钮由后端返回的可执行动作控制，不能只按前端状态判断 |
| `版本：If-Match-Version` | 编辑、状态变更等请求携带乐观锁版本 |
| `幂等：Idempotency-Key` | 创建、提交、支付、退款、发货、核销等写操作携带唯一键 |

### 1.3 全页面通用规则

1. 业务 ID 均以字符串保存和传输；金额使用字符串，例如 `"39.90"`，不转 `Number`。
2. 列表响应按 `data.items`、`data.pageNo`、`data.pageSize`、`data.total`、`data.totalPages` 绑定；空列表显示空态，不能视为接口错误。
3. 所有表单文本字段提交前由服务端检测；前端展示检测状态/失败原因，不展示敏感词原文。
4. 文件上传先调用 `POST /files`，使用 multipart 字段 `file`；成功响应取 `data.id` 作为业务 `fileId`，表单和业务接口仅提交该 ID 或 ID 数组。私有下载只使用 `POST /files/{fileId}/download-url` 返回的短期 `data.downloadURL`，不得读取或拼接 COS 地址。
5. 通用错误处理：`AUTH_*` 跳转/提示登录，`VALIDATION_*` 映射字段错误，`VERSION_CONFLICT` 刷新详情，`STATE_TRANSITION_NOT_ALLOWED` 刷新状态并提示，`IDEMPOTENCY_CONFLICT` 提示勿重复提交，库存/名额不足保留当前表单供用户重选。

## 8. 未覆盖接口与前端处理边界

1. 外部服务回调（物流、存证）仅后端接收，前端不调用。
2. 生产环境支付统一跳转微信支付 V3 H5；不制作独立支付渠道选择或数字人民币钱包表单。Mock 支付只允许测试环境通过业务页面触发。
3. `POST /exports`、存证重试、风险处置等高风险操作需要二次确认弹窗、原因输入和结果轮询；具体按钮仅对有权限角色展示。
4. API 未明确的页面级展示字段，应在后端补充只读 DTO 后再绑定；禁止前端通过组合内部接口、猜测 ID 或读取数据库补足。

## 9. 页面交付验收

每个前端页面完成时应核对：页面字段、控件和选项与字段清单一致；接口字段与本清单/OpenAPI 一致；状态和按钮以服务端结果为准；成功、空态、失败、处理中、无权限和状态冲突均有 UI；关联的测试用例已执行并记录。
> B04 查询规则：平台管理员页面和版权合规审核列表必须请求 `GET /api/v1/auth-plans?enabledOnly=false`，否则默认只返回 `ENABLED` 方案；只有城市 IP 的可用方案下拉请求 `enabledOnly=true`。
