# 星衍树消费者 H5 前端 AI 开发包

## 1. 用途与唯一入口

本目录是消费者 H5 的唯一交付入口。前端 AI 仅以本目录为准，不读取总包内旧 H5 原型、旧“暂不开发消费者 H5”说明或后台角色文档来推导 H5 功能。

消费者 H5 只展示商品、活动与平台服务；禁止展示 IP、创作者、品牌、授权方案/合同、权利证明、审核意见、内部分账、存证回执及后台菜单。

## 2. 阅读顺序

1. `H5前端AI启动指令.md`：本次可做范围及交付要求；
2. `页面与交互说明.md`：路由、页面字段、状态与交互；
3. `操作逻辑说明.md`：用户操作、接口调用、异常和状态流转；
4. `H5接口契约与联调状态.md`：实际可调用接口与尚未实现的接口边界；
5. `业务规则与数据安全.md`：隐私、购物车、订单、地址、支付与履约规则；
6. `联调与验收说明.md`：自测与联调清单；
7. `原型/星衍树消费者H5原型_v0.5.html`：仅作视觉与交互参考。

## 3. 当前开发边界（2026-10-09）

| 范围 | 前端处理方式 |
| --- | --- |
| 公开商品、活动、图片、客服、地区 | 可直接调用后端接口联调 |
| 短信登录、协议确认、会话刷新/退出、个人中心摘要 | 可直接调用后端接口联调 |
| 购物车、地址簿、结算页、支付结果、商品订单页 | API-H5-02 已实现，可按本包契约联调；购物车仍仅浏览器本地状态 |
| 活动预约、免费/收费票、核销码 | API-H5-03 已实现，可按本包契约联调；核销动作仍等待 API-FUL-02 |
| 物流、售后、退款 | 暂不制作真实接口调用链，等待后续任务 |

## 4. 版本与冲突处理

- 当前实现事实优先于旧总包中的预置 OpenAPI 条目。
- 任何没有在 `H5接口契约与联调状态.md` 标为“已实现”的接口，均不得请求真实后端。
- 后端完成 API-H5-02、API-H5-03、API-FUL-01 或 API-AFS-01 后，先更新本目录的契约、操作逻辑、原型和验收用例，再下发前端联调。
