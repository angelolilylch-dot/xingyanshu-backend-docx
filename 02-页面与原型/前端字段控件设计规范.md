# 星衍树一期 MVP 前端字段控件设计规范

版本：v0.4  
状态：当前已实现接口的前端原型与开发强制规范  
适用范围：统一后台登录、账号与组织、平台配置、平台 IP 管理、城市 IP 管理、IP 合规审核、授权方案管理。  
关联文档：[页面功能与字段清单.md](页面功能与字段清单.md)、[前端页面与接口字段绑定清单.md](前端页面与接口字段绑定清单.md)、[OpenAPI_v0.4.yaml](OpenAPI_v0.4.yaml)。

## 1. 使用规则

1. 本文件定义字段在页面上的表现形式，优先于原型中的简化展示；原型必须据此逐项调整。
2. `必填`指提交当前动作时必填，不等于保存草稿时必填。带“文字检测”的输入，提交后等待服务端检测结果。
3. 所有选择型字段展示中文名称，接口提交稳定编码或 ID；不得把中文名称直接作为枚举值提交。
4. 文件先调用 `POST /api/v1/files`，业务表单只提交返回的 `fileId` 或 `fileIds`。不得保存或展示 COS 长期地址。
5. `只读`字段必须使用只读文本、状态标签或文件预览，不得渲染为可编辑输入框。

## 2. 通用控件与文件限制

| 类型 | 页面表现 | 通用限制 |
| --- | --- | --- |
| 单行文本 | 带标签的 `input[type=text]` | 显示字数上限；编号类不自动截断；不得输入前后空格。 |
| 多行文本 | `textarea`，下方显示剩余字数 | 最小高度 120px；审核意见、说明、介绍等不得缩成单行。 |
| 下拉单选 | 可搜索下拉或普通下拉 | 固定枚举使用普通下拉；组织、地区、方案、模板使用可搜索下拉。 |
| 单选按钮组 | 横向或换行排列的 radio | 适用于 2-5 个互斥业务决策；不得用下拉隐藏关键审核结论。 |
| 复选框组 | 分组复选标签 | 多选项应显示已选数量；至少选一项时在提交前校验。 |
| 数值 / 金额 / 比例 | 带单位的数字输入 | 金额保留两位小数；比例按百分数输入，接口传 `0~1` 小数；总比例必须等于 100%。 |
| 日期 | `input[type=date]` | 日期不允许手工填写无效文本；起止日期需实时校验先后顺序。 |
| 文件上传 | 上传按钮 + 已上传文件列表 | 每个文件显示原始名称、格式、大小、上传状态、预览/删除；草稿可删除未引用文件。 |
| 图片上传 | 图片上传按钮 + 缩略图排序列表 | 封面仅 1 张；详情图可多张并支持排序；必须显示上传失败原因。 |

| 文件类别 | 允许格式 | 单文件大小 | 数量与附加规则 |
| --- | --- | --- | --- |
| IP 封面图 | JPG、JPEG、PNG、WebP | 10MB | 必传 1 张；建议比例 1:1 或 4:3；上传后可替换。 |
| IP 详情图 | JPG、JPEG、PNG、WebP | 10MB | 可多张，建议最多 10 张；保存提交有序 `detailFileIds`。 |
| 版权证明、DCI 证书 | PDF、JPG、JPEG、PNG | 30MB | 版权证明至少 1 份；DCI 文件为提交合规时必传。 |
| 评估报告 | PDF、DOC、DOCX、XLS、XLSX、JPG、JPEG、PNG | 30MB | 每次上传 1 个报告文件；一份 IP 可保留多条报告记录。 |
| 授权委托书 | PDF、JPG、JPEG、PNG | 30MB | 仅企业/工作室资料留存使用；当前不作为购买或登录前置。 |

不允许的文件类型、超出大小、空文件或伪造扩展名必须在前端提示，并以服务端 `FILE_TYPE_NOT_ALLOWED`、`FILE_SIZE_EXCEEDED`、`FILE_CONTENT_INVALID` 的最终校验结果为准。

## 3. A01 统一后台登录与创作者注册

消费者只在 H5 登录，不出现在本页。后台登录页不提供角色选择；服务端根据账号识别账号类型，登录后通过 `/auth/me` 返回角色、菜单和数据范围。

| 区域 | 字段 | 表现形式 | 必填与限制 | 接口绑定 |
| --- | --- | --- | --- | --- |
| 后台登录 | 账号 | 单行文本 | 必填；非创作者为 2-50 位英文、数字、下划线或连字符；创作者填写已注册手机号。 | `account` |
| 后台登录 | 密码 | 密码输入框，带显示/隐藏图标 | 必填，8-64 位；不得回显或写日志。 | `password` |
| 后台登录 | 图形验证码 | 单行文本 + 图形图片 + 刷新图标按钮 | 所有后台角色必填；先获取图形验证码，过期或失败后刷新。 | `captchaId`、`captchaCode` |
| 创作者注册 | 手机号 | 单行文本 | 必填，11 位中国大陆手机号。 | `mobile` |
| 创作者注册 | 短信验证码 | 单行文本 + 获取验证码按钮 | 必填，6 位；获取按钮有倒计时。 | `smsCode` |
| 创作者注册 | 设置密码 | 密码输入框 | 必填，8-64 位。 | `password` |
| 创作者注册 | 显示名称 | 单行文本 | 必填，2-128 字；文字检测。 | `displayName` |
| 创作者注册 | 用户须知、隐私政策 | 两个独立复选框 + 可打开文本链接 | 两项均必选；未勾选禁止注册。 | 前端同意记录 / 后续审计 |

## 7. B02 城市 IP 管理

### 7.1 列表与动作

列表首行提供关键词搜索框和“新建 IP”按钮；详情页按八个分区展示。草稿或补充材料状态显示“编辑、上传评估报告、申请 DCI 代办、提交审核”；其他状态只读展示进度和退回意见。

| DCI | 尚未取得 DCI | 复选框 | 勾选后显示代办表单；勾选状态下禁止提交审核。 |
| DCI 代办 | 联系人 | 单行文本 | 申请代办必填，最多 100 字。 |
| DCI 代办 | 联系电话 | 单行文本 | 申请代办必填，11 位手机号或固定电话；页面列表脱敏。 |

## 8. B03 IP 合规审核

| 页签/区域 | 字段 | 表现形式 | 限制 |
| --- | --- | --- | --- |
| 待审核 IP | 关键词、DCI 状态 | 单行搜索框、下拉筛选 | 当前队列接口支持 `keyword`、`dciCertificateStatus`、分页。 |
| 待审核 IP | IP 编号、名称、城市、权利人、DCI 状态、初选方案、评估报告、下一步 | 表格 + 状态标签 + 主操作按钮 | 点击“核验 DCI/确认权属”在“审核详情”打开。 |

## 10. 原型验收要求

1. 原型中每个字段必须能在本文件找到同名行；不得以通用输入框替代规定的下拉、单选、复选、日期或只读控件。
2. B02 必须完整显示八个表单分区，长文本必须使用多行输入，图片和报告必须显示文件限制与上传结果。
3. B03 必须保留“待审核 IP / 审核详情 / DCI 代办”三个页签，并按本文件区分只读材料与审核可编辑字段。
4. 文件和报告的格式、大小、单多文件规则必须在上传控件附近可见；前端校验失败应明确说明原因。
5. 登录页不显示角色下拉；消费者不出现在本页；后台账号和创作者均显示图形验证码输入与刷新动作，登录后以 `/auth/me` 初始化菜单和工作台。
