# 星衍树版权二创平台一期 MVP 页面功能与字段清单

版本：v0.4  
状态：开发基线  
依据：[一期MVP需求基线与范围说明.md](一期MVP需求基线与范围说明.md)、[业务状态机与流转规则.md](业务状态机与流转规则.md)

## 1. 使用说明与范围

本清单定义一期 MVP 的页面、可见功能、列表字段、详情字段、提交字段和关键校验，用于前端页面开发、后端 API、数据库字段字典、测试用例与 AI 任务拆分。

- 页面分为统一管理后台和消费者 H5 两端；消费者不进入管理后台，创作者 IP 商城不在消费者 H5 展示。
- 本文仅列出一期实际需要的字段。数据库公共字段、审计字段、状态历史、文件表和快照表不在每个页面重复罗列。
- 页面中的“必填”表示在该动作提交时必填；“展示”表示只读展示；“系统”表示由系统写入，前端不得允许编辑。
- 所有用户主动提交的文字字段均调用第三方敏感内容检测。对于商品、活动，检测疑似、不通过或异常均禁止发布；作品的疑似风险进入版权/合规人工复核。
- 具体状态值、状态转换、超时和并发控制以《业务状态机与流转规则》为准。

### 1.1 一期不应出现在页面或表单中的能力

下列内容已明确不属于一期 MVP，不得从旧原型或旧字段清单沿用：

- 商品、活动草稿保存、草稿编辑、撤回草稿、删除草稿；
- 商品/活动的人工内容发布审核、城市运营审核、平台管理员发布审核；
- 发票、优惠券、满减、会员价、复杂营销、限购规则；
- 到店自提、线下取货、换货、补发、维修、改期；
- IP 或授权自动续期、团队多账号、用户自助注销、实名信息自助修改；
- 数字人民币支付、智能合约自动分账；
- 图片 OCR、图片/视频/音频敏感内容识别；
- 投诉工单、在线客服聊天；消费者仅展示平台客服电话。

### 1.2 通用字段与字段表达

所有核心表默认应具备：`id`、`status`、`status_reason_code`、`status_reason`、`version`、`created_at`、`created_by`、`updated_at`、`updated_by`、`status_changed_at`、`status_changed_by_type`、`status_changed_by_id`。列表页按权限展示创建/更新时间与状态；敏感原文、实名原件、收款账号、详细地址等按最小权限脱敏。

| 标记 | 含义 |
| --- | --- |
| 必填 | 当前动作必须提交 |
| 条件必填 | 由主体类型、履约方式、售后类型等决定 |
| 展示 | 后端返回，只读 |
| 系统 | 服务端生成或维护，不从普通表单提交 |
| 快照 | 在下单、发布、审核、合同、退款或结算节点固化 |

## 3. 管理后台通用页面

### A01 后台登录

**角色：** 平台管理员、集团管理层、城市运营、版权/合规、创作者、财务、履约客服。  
**功能：** 账号密码登录、图形验证码、首次登录绑定手机号、退出登录。

| 区域 | 字段 | 属性 | 规则 |
| --- | --- | --- | --- |
| 登录表单 | 账号 | 必填，文本输入框 | 创作者自主注册账号；其他后台账号由平台管理；`2-50` 位，仅限英文字母、数字、下划线、连字符，首尾必须为字母或数字；不支持手机号登录 |
| 登录表单 | 密码 | 必填 | 加密传输与不可逆存储校验 |
| 登录表单 | 图形验证码 | 必填 | 有效期、错误次数与刷新机制由配置控制 |
| 首次登录 | 手机号 | 条件必填 | 后台首次登录时绑定；必须通过短信验证 |
| 系统返回 | 登录结果、角色、可见菜单、数据范围 | 系统 | 根据 RBAC 和账号状态返回 |

停用账号不得登录。登录、登出、验证码失败均写审计日志。

### A02 集团管理层经营看板 / 首页

**功能：** 集团管理层查看全平台经营汇总、趋势与风险摘要；只读，不在首页执行跨权限操作。

| 角色 | 卡片和列表字段 |
| --- | --- |
| 集团管理层 | IP、授权、交易、履约、退款、结算、风险汇总指标及趋势 |

除集团管理层外，其他后台角色登录后按 `GET /auth/me` 返回的第一个可见菜单进入对应业务页面，不进入 `/dashboard`。

### A03 账号与组织

侧栏只保留“账号与组织”一个业务域入口，页面内以“账号管理 / 组织管理”页签承载列表、新增、编辑、启用和停用动作；原 A09 不再作为独立侧栏菜单。

**角色：** 平台管理员。  
**功能：** 查询后台账号、创建/停用/恢复账号、分配角色和数据范围；不在本页修改创作者或消费者实名资料。

| 列表字段 | 新增/编辑字段 | 校验 |
| --- | --- | --- |
| 账号、姓名/显示名、手机号脱敏、所属组织、角色、数据范围、账号状态、最后登录时间、创建时间 | 新增：账号、初始密码、姓名/显示名、手机号、所属组织、角色、数据范围；编辑：姓名/显示名、手机号、所属组织、角色、数据范围；状态操作：状态、原因 | 账号唯一且新增后不可编辑；账号为 `2-50` 位英文、数字、下划线或连字符，首尾为英文或数字；初始密码仅新增时填写且不回显；角色决定可选数据范围；停用需填写原因并撤销会话 |

停用创作者时联动禁止登录、购买、提交和下载；历史合同、订单、存证不可删除。

### A04 角色与权限配置

**角色：** 平台管理员。  
**功能：** 维护预置角色的菜单、按钮、数据、导出和文件下载权限。

| 列表字段 | 表单字段 |
| --- | --- |
| 角色名称、角色编码、适用端、数据范围、状态、更新时间 | 角色名称、角色说明、菜单权限、按钮权限、数据范围、导出权限、文件下载权限、状态 |

一期角色以预置角色为主。权限变更必须记录前后差异并生效于后续会话。

### A09 组织管理（A03 页面内页签）

**角色：** 平台管理员。
**功能：** 维护集团、平台和城市组织；城市组织为城市运营账号及城市 IP 数据范围提供唯一的 `cityCode` 来源。

| 列表字段 | 新增/编辑字段 | 校验 |
| --- | --- | --- |
| 组织编码、组织名称、组织类型、上级组织、城市编码、状态、版本、更新时间 | 组织编码、组织名称、组织类型、上级组织、城市编码；状态操作：状态、原因 | 组织编码全局唯一且创建后不可编辑；组织类型为集团、平台、城市；城市组织必须选择上级组织并填写城市编码；非城市组织不得填写城市编码；有启用账号或下级组织时不得直接停用 |

账号管理中的“所属组织”只能通过组织下拉选择已启用组织，不允许手工输入 `orgId`。城市运营账号必须选择城市组织，且其数据范围为“本城市”时，以该组织的 `cityCode` 过滤业务数据。

### A05 平台配置

侧栏只保留“平台配置”一个业务域入口，页面内以“平台参数 / 地区管理 / 标签管理 / 固定售后模板”四个页签承载操作；原 A06 不再作为独立侧栏菜单。

**角色：** 平台管理员。  
**功能：** 一个页面内提供“平台参数”“地区管理”“标签管理”三个选项卡；维护平台客服电话、服务时间、服务说明、平台退货地址及各项参数，并维护可用地区和 IP 标签。

| 选项卡 | 页面内容 | 主要操作 | 业务边界 |
|---|---|---|---|
| 平台参数 | 服务电话、服务时间、服务说明、退货地址、待支付关闭分钟数、售后保护期、外部服务启用状态 | 保存非敏感配置 | 外部密钥只在私有配置文件中管理，页面仅显示脱敏的配置状态 |
| 地区管理 | 地区编码、地区名称、层级、上级地区、排序、启用状态 | 新增、启用、停用、查询 | 地区编码使用六码行政区划编码；层级和上级地区由编码推导 |
| 标签管理 | 标签类型、标签名称、标签编码、排序、启用状态 | 新增、启用、停用、查询 | 标签类型固定为地域、文化、品类、商业化；标签本身由平台管理员维护 |

固定枚举（如 IP 类型、授权方式、售后类型、DCI 状态）由系统初始化写入字典表，只读使用，不在 A05 提供编辑入口。

| 配置项 | 字段 |
| --- | --- |
| 客服信息 | 平台客服电话、服务时间、服务说明、启用状态 |
| 平台退货地址 | 收件人、联系电话、省/市/区、详细地址、邮编、启用状态 |
| 订单与消息参数 | 待支付关闭分钟数、售后保护期天数、短信验证码有效期/频率/错误次数 |
| 外部服务参数 | 短信、物流、文件存储、实名、敏感内容检测、链上存证服务配置标识、启用状态 |

密钥、令牌、回调验签密钥只允许后端加密保存，前端仅展示脱敏状态和最后更新时间。

### A06 固定取消/退款模板管理（A05 页面内页签）

**角色：** 平台管理员。  
**功能：** 维护商品售后模板、活动取消/退款模板；创作者仅可选择，不可自由填写规则。

| 列表字段 | 新增/编辑字段 | 关键校验 |
| --- | --- | --- |
| 模板编号、模板名称、适用业务、适用条件、退款规则摘要、启用状态、版本、更新时间 | 模板名称、适用业务（商品/活动）、适用条件、申请时间窗口、可退款比例/金额规则、退货费用承担规则、规则说明、启用状态 | 已被商品/活动发布版本引用的模板不得直接修改，需新建版本 |

### A07 敏感内容检测记录

**角色：** 平台管理员、版权/合规（仅本人权限范围）。  
**功能：** 查询第三方检测调用和处理结果，不展示敏感词原文。

| 查询条件 | 列表字段 | 详情字段 |
| --- | --- | --- |
| 业务类型、对象编号、结果、检测时间范围、服务状态 | 检测编号、业务类型、对象编号、提交人、结果、风险类别、服务商请求号、检测时间、重试次数 | 检测请求摘要、脱敏结果说明、关联提交版本、处理去向、错误码、审计日志 |

### A08 文件、存证与审计日志

**角色：** 平台管理员；版权/合规、财务、集团管理层按数据范围只读。  
**功能：** 查询文件访问、存证、业务审计和导出记录。

| 子页 | 列表字段 | 详情字段 |
| --- | --- | --- |
| 文件记录 | 文件编号、业务对象、文件类型、版本、Hash、访问权限、上传人、上传时间、状态 | 存储标识、授权下载记录、关联对象、Hash、访问日志 |
| 存证记录 | 存证编号、对象类型、对象编号、Hash、链平台、上链状态、回执编号、上链时间 | 请求编号、失败原因、重试记录、关联文件/快照 |
| 审计日志 | 日志编号、操作人、角色、对象、操作、前状态、后状态、结果、时间、IP | 请求标识、失败原因、操作备注 |
| 导出记录 | 导出编号、导出对象、申请人、范围、脱敏级别、状态、下载时间 | 导出原因、审批/授权信息、文件有效期、下载日志 |

## 4. IP、权利与授权方案页面

### B01 平台 IP 管理

仅平台管理员显示此侧栏入口。IP 列表和详情在同一业务域内查看；确权成功、存证成功且前置条件满足后由系统自动上架，不提供人工上架按钮；上架记录不单列菜单。

**角色：** 城市运营（仅本城市）、版权/合规、平台管理员、集团管理层只读。  
**功能：** 检索 IP、查看状态和进入详情；城市运营仅可新建、编辑草稿/补充材料中的本城市 IP。

| 查询条件 | 列表字段 |
| --- | --- |
| IP 编号/名称、主归属城市、IP 类型、权利人类型、主状态、DCI 证书状态、授权方式、上架状态、创建时间 | IP 编号、IP 名称、封面缩略图、IP 类型、主归属城市、原始权利人名称/类型、DCI 证书状态、授权方式、授权方案、主状态、商城状态、存证状态、创建人、更新时间 |

### B02 城市 IP 管理

城市运营仅显示此一个侧栏入口。在同一入口中完成 IP 列表、新建、草稿编辑、补充材料、评估报告上传、DCI 代办申请、提交合规审核和审核进度查看。

**角色：** 城市运营。  
**前置：** 只能处理本人数据范围内，且状态为 `DRAFT` 或 `SUPPLEMENT_REQUIRED` 的 IP。

| 分组 | 字段 | 属性 |
| --- | --- | --- |
| 基本信息 | IP 名称、IP 类型、资源来源、文化背景和故事、一句话简介、完整介绍、IP 特色 | 必填；文字检测 |
| 商城展示 | 封面图/缩略图、详情图、可创作方向、适用商品类型、适用文旅活动类型、地域标签、文化标签、品类标签、商业化标签、面向创作者版权说明、购买须知 | 图片条件必填；文字检测 |
| 主归属与权利人 | 主归属城市、权利人名称、权利人类型（个人/企业/机构/集体组织）、权利取得方式、权属说明 | 必填；一个 IP 仅一个原始权利人 |
| 版权证明 | 证明类型、证明编号、证明文件、有效期 | 必填；文件上传 |
| DCI 版权证书 | DCI 证书编号、DCI 证书文件、DCI 状态 | DCI 证书必填；未取得时允许保存草稿并申请代办，不得提交审核 |
| DCI 代办申请 | 联系人、联系电话、方便联系时间、补充说明 | DCI 缺失时显示“申请 DCI 代办”；联系方式加密存储、脱敏展示 |
| 评估报告 | 报告编号、评估机构、评估日期、有效期、报告文件 | 非必填；城市运营可在录入 IP 时上传，版权/合规可后续新增或补传 |
| 方案选择 | 固定授权方案、分账结构模板、期望分账比例 | 必填；仅可选已启用方案/模板；选择模板后填写各参与方比例且合计100% |
| 提交信息 | 提交说明 | 提交审核时必填；文字检测 |

**页面动作：** 保存 IP、上传/替换尚未确权的材料、申请 DCI 代办、提交版权/合规审核、查看退回意见。DCI 缺失或已申请代办时只能保存，提交时校验资料完整、DCI 证书已上传、方案有效、权利人唯一、主归属城市已确定。

### B03 IP 合规审核

版权/合规仅显示此一个侧栏入口，页签为“待审核 IP / 审核详情 / DCI 代办”。审核详情由待审核 IP 选中后在当前业务域内打开，不增加独立侧栏菜单。

**角色：** 版权/合规；城市运营可查看本人数据及退回意见；平台管理员只读或风险处置。  
**功能：** 审核权利证明、授权边界和方案匹配；上传评估报告；确权或退回补充。

| 区域 | 展示/表单字段 |
| --- | --- |
| IP 摘要 | IP 编号、名称、主归属城市、IP 类型、当前状态、创建人、提交时间 |
| 权利审查 | 原始权利人、类型、取得方式、权属说明、证明类型/编号/有效期/文件、DCI 证书编号/文件/状态、历史审核记录 |
| 展示资料 | 封面、详情图、介绍、标签、可创作方向、公开版权说明、购买须知 |
| 方案审查 | 城市运营选择的授权方案/分账结构模板、期望分账比例、授权方式、期限、地区、场景、内容类型、名额、价格、分配规则摘要 |
| 评估报告 | 报告编号、机构、日期、有效期、报告文件、上传人 |

## 10. 开发验收检查点

1. 每个页面只向有数据权限的角色展示，并按字段进行脱敏。
2. 页面动作必须受对象当前状态约束，前端可隐藏不可用按钮，后端必须再次校验。
3. 商品和活动页面没有人工内容审核按钮；提交后只展示系统校验中、已发布、校验不通过或校验异常等状态。
4. 作品页面存在版权初审、合规复核、退回补充和确权动作；作品没有草稿保存。
5. 授权方案一旦绑定 IP，页面不显示编辑、停用和删除动作。
6. 商品详情、订单详情、活动详情和预约详情都可追溯到提交时的授权、规则、价格和内容快照。
7. 售后页面不提供换货、补发、维修、改期；退款最终由财务复核，履约客服不能越权完成退款。
8. 独家买断页面、订单和分账明细正确区分买断费用分配与后续商品/活动不分账规则。
9. 所有文件下载使用临时链接；合同、实名、版权证明、收款账户、收货地址按角色最小化展示。
10. 所有表单文字与状态变更均有检测、审计和失败提示；检测异常默认阻断发布或流转。

## 11. 表单控件类型、下拉选项与字典值

本章补充页面字段的输入控件和固定选项。除非特别标注，所有下拉和单选值应同时保存稳定枚举值与展示名称；前端使用展示名称，接口与数据库传递枚举值。自由录入的文字字段仍须经过敏感内容检测。

### 11.1 通用控件约定

| 控件类型 | 使用规则 |
| --- | --- |
| 单行文本 | 名称、编号、简短说明等；设置最大长度，由字段字典具体定义 |
| 多行文本 | 介绍、说明、意见、原因；须敏感内容检测 |
| 下拉单选 | 选项固定、一次只选一项；无“其他”时不得自由录入 |
| 搜索下拉 | 从已有主数据或本人权限范围内数据检索选择，如 IP、方案、作品、订单 |
| 单选按钮 | 少量且互斥的业务决策；页面直接展示全部选项 |
| 复选框组 | 可多选标签、内容类型、权限等；至少一项规则须明确 |
| 开关 | 是/否、启用/停用等二值项；保存为布尔值 |
| 日期/时间 | 日期、日期时间、日期范围；使用统一时区 Asia/Hong_Kong |
| 金额 | 金额输入框，单位人民币元，精确到分，不得输入负数 |
| 数量 | 整数输入框，最小值 0 或 1 由页面规则确定 |

| 只读 | 仅展示系统快照、状态、编号、计算金额和外部回执，不允许客户端修改 |
