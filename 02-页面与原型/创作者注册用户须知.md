# 星衍树创作者注册用户须知

欢迎使用星衍树版权二创平台（以下简称“平台”）创作者服务。请您在注册前认真阅读并充分理解本《创作者注册用户须知》（以下简称“本须知”）。当您勾选“我已阅读并同意《创作者注册用户须知》”并提交注册，即表示您已阅读、理解并同意遵守本须知。

## 一、适用范围

本须知适用于通过平台注册创作者账号的个人、企业及工作室主体。

创作者账号用于完成主体实名认证、浏览平台已开放的 IP 商城内容，以及在平台后续已开放的业务范围内开展授权相关操作。消费者端 H5 与创作者端为不同入口和业务身份，消费者账号不适用本须知。

## 二、注册条件与账号使用

1. 您应使用本人或本主体可正常接收短信验证码的手机号码进行注册，并确保注册信息真实、准确、完整、有效。
2. 注册时需要提交手机号码、登录密码、短信验证码及显示名称。手机号码用于账号识别、登录验证、账户安全通知及必要的业务联系。
3. 您应妥善保管账号、密码、短信验证码及登录令牌，不得向他人泄露，不得出租、出借、出售、转让或以其他方式允许他人使用您的账号。
4. 如发现账号存在异常登录、密码泄露、验证码被盗用或其他安全风险，请及时修改密码并联系平台处理。
5. 您不得利用平台账号从事违法违规活动，不得发布、提交或传播虚假、侵权、违法、有害或损害平台及他人合法权益的信息。

## 三、实名认证说明

1. 注册成功后，您可以进入“注册/实名认证”页面提交主体认证资料。平台注册与实名认证为两个独立步骤：注册成功不等同于完成实名认证。
2. 当前支持个人、企业、工作室三种主体类型。
3. 实名认证需根据主体类型提交相应信息，包括主体类型、真实姓名或企业/工作室名称、证件类型及证件号码或统一社会信用代码。
4. 请确保实名认证资料与实际主体一致。不得冒用他人身份、盗用企业信息、伪造证件、虚构工作室主体或提交其他不真实、不合法材料。
5. 未完成实名认证的创作者可浏览已开放的 IP 商城内容；需要进行身份核验的业务，应以平台页面提示及实际业务规则为准。
6. 平台会展示您的实名认证状态，例如“未认证”“认证中”“已认证”。为保护信息安全，证件号码等敏感信息仅用于提交及核验，不会在页面完整回显。
7. 如您提交的信息存在错误、失效、与实际主体不一致，或平台发现存在风险，平台有权要求补充、修改资料，或限制相关功能的使用。

## 四、企业及工作室授权委托书说明

1. 企业或工作室主体完成实名认证后，平台可依据您填写并核验通过的企业或工作室名称，自动生成一份授权委托书 Word 草稿，供您下载使用。
2. 自动生成的 Word 草稿仅作为待补充、签署或盖章的文档模板，不代表平台已确认授权关系，也不代表该文件已经签署、生效或完成留存。
3. 您下载草稿后，应自行核对主体名称及文档内容，并根据实际情况补充受托人、授权期限、签署日期等信息，完成签字或盖章。
4. 如您需要在平台留存签署后的委托书，可按页面指引上传签署件。已留存仅表示平台保存了该文件资料，不当然代表平台对文件真实性、法律效力或授权范围作出保证。
5. 授权委托书草稿下载链接具有时效性。链接失效后，您可通过平台提供的刷新方式重新获取短期下载链接；请勿将下载链接长期公开传播或转交无关人员。

## 五、资料真实性与合法性承诺

1. 您承诺所提交的注册信息、实名认证信息、授权委托书及后续业务资料均真实、准确、完整、合法、有效。
2. 您承诺对所提交资料拥有合法的提交、使用及授权权限，不侵犯任何第三方的姓名权、名称权、商标权、著作权、肖像权、商业秘密、隐私权或其他合法权益。
3. 如因您提供虚假资料、冒用身份、超越授权范围、侵害第三方权益或违反法律法规而引发争议、投诉、索赔、处罚或损失，应由您自行承担相应责任；平台有权根据实际情况限制、暂停或终止相关账号及服务。

1. 平台展示的 IP 内容、授权方案、价格、可用范围及限制条件，以平台页面实际展示和后续正式授权文件为准。

4. 未经合法授权，您不得擅自使用平台 IP 内容制作作品、商品、宣传材料、线上内容或其他衍生内容。

## 七、信息保护与隐私说明

1. 平台将在提供账号注册、身份核验、文件留存、授权业务及账户安全服务所必需的范围内处理您的相关信息。
